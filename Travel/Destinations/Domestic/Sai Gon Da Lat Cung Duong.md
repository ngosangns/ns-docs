# Sài Gòn – Đà Lạt: các cung đường chạy trong ngày

Ghi lại ngày 2026-09-22. Giữ nguyên lời khuyên gốc, kể cả mốc thời gian trong note ("mùa này", QL28B "để 2026").

## 1. Cung quốc dân

Ai cũng đi:

Sài Gòn → Dầu Giây → QL20 → đèo Chuối → đèo Bảo Lộc → Di Linh → Đức Trọng → đèo Prenn → Đà Lạt.

Ngán đèo Prenn thì quẹo Mimosa hoặc Sacom cũng ổn.

## 2. Cung chill

Sài Gòn → Dầu Giây → chợ Madagui → DT721 → Đạ Tẻh → DT725 → Mỹ Đức → đèo Con Ó → đèo B40 → B'Lá → Bảo Lâm → đèo Tân Thanh → Lâm Hà → đèo Tà Nung → Đà Lạt.

Mùa này phượt ngang mấy vườn sầu riêng ở Đạ Huoai – Đạ Tẻh thì thơm nức mũi.

## 3. Biển và hoang mạc Bác Ái – Tây Bắc Ninh Thuận

Sài Gòn → QL1A → Bình Thuận → Vĩnh Hảo → Cà Ná → Ninh Chữ → Vĩnh Hy → KDL Ba Hồ → Tây Bắc Ninh Thuận → đèo Sông Pha → đèo D'Ran → Cầu Đất → Đà Lạt.

## 4. Nối Bình Thuận – Lâm Đồng

- **a.** Sài Gòn → Xuân Lộc → Chứa Chan → Mê Pư → Tà Pao → Đa Mi → Bảo Lộc → theo cung 1 đến Đà Lạt. Tiện ghé Đức Mẹ Tà Pao, hồ Đa Mi, cafe Sim Tím, Linh Quy Pháp Ấn.
- **b.** Sài Gòn → ngã 3 Tân Minh → QL55 → Tà Pao → Đa Mi → Bảo Lộc → Đà Lạt.
- **c.** Sài Gòn → Phan Thiết → QL28 → Ma Lâm → Gia Bắc → Di Linh → Đà Lạt. Cung này tha hồ ăn cua.
- **d.** Sài Gòn → Phan Thiết → QL28B → đèo Đại Ninh → Bắc Bình → Di Linh → Đà Lạt. Cung này hơi xấu, để 2026 đi.

## 5. Dư xăng

Sài Gòn → Nha Trang → QL27C → Khánh Vĩnh → đèo Khánh Lê (Omega) → Xóm Lèo → Đà Lạt. Cung này bao đẹp.

Hoặc tới TP Phan Rang quẹo trái QL27: Ninh Sơn → Sông Pha → D'ran → Đà Lạt.

## 6. Vòng kiểu "ai dám đi không"

Sài Gòn → Bình Dương → Đồng Xoài → QL14 → Gia Nghĩa → Ban Mê Thuột → QL27 → Cư Kuin → Lắk → Đam Rông → Phi Liêng → Phi Tô → đèo Tà Nung → Đà Lạt.

Tới ngã 3 Phi Tô đừng đi thẳng về Lâm Hà. Quẹo trái lên Phi Tô rồi ra ngay chân cafe Mê Linh.

Tới Gia Nghĩa có thể quẹo vào QL28 đi đèo Quảng Khê, ghé Tà Đùng rồi ra DT725 như cung 2.

Mùa này lên Đà Lạt thì đúng bài.
