# Concepts

* [SKILL](.agents/skills/mdvdb-search-docs/SKILL.md) - Search indexed markdown (.md) files across an mdvdb Collection or inside a named Shard/sub-collection using semantic, lexical, or hybrid search. Supports frontmatter and relation filters, score thresholds, time decay, link-hop boosting, and resolving relations with --populate. Use when you need to find information across a vault or within one reusable folder scope.
