# Concepts

- [SKILL](.agents/skills/mdvdb-write-document/SKILL.md) - Create a new markdown (.md) document optimized for mdvdb indexing. Generates proper YAML frontmatter based on the vault's schema (including typed relation and File inputs while respecting read-only computed fields), structured headings for chunking, and wiki/markdown links to related files for graph connectivity. Use when creating new documents in an mdvdb vault, including documents with media, file attachments, or schemas containing Lookup or Rollup outputs.
