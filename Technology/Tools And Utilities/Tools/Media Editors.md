## PDF

- https://github.com/Stirling-Tools/stirling-pdf — Stirling PDF: an open-source (open-core) PDF platform. Runs as a desktop app, a browser UI, or self-hosted (`docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf`). 50+ tools: edit, merge, split, sign, redact, convert, OCR, compress; includes no-code workflows and its own API, and files never have to be sent to an external service. Docs: https://docs.stirlingpdf.com
