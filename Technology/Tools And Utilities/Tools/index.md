# Concepts

- [Developer Tools And Environments](Technology/Tools%20And%20Utilities/Tools/Developer%20Tools%20And%20Environments.md) - Local dev environment managers, benchmarks, debugging, monitoring and other software development tools.
- [Deterministic Avatars](Technology/Tools%20And%20Utilities/Tools/Deterministic%20Avatars.md) - RoboHash, DiceBear, and Peek turn a string into a stable avatar. RoboHash composites licensed artwork over HTTP or Python, published DiceBear is 10.7 with 61 styles while 11 is still a release candidate, and Peek is a small MIT SVG face with an optional React 19 component.
- [Diagram Tools](Technology/Tools%20And%20Utilities/Tools/Diagram%20Tools.md) - Crow's foot notation reference and a list of tools for drawing architecture and database diagrams.
- [Git And GitHub](Technology/Tools%20And%20Utilities/Tools/Git%20And%20GitHub.md) - Git and GitHub tools, self-hosted servers, hooks and a guide to rewriting history with git filter-repo.
- [Insomnia Mac Keep Awake](Technology/Tools%20And%20Utilities/Tools/Insomnia%20Mac%20Keep%20Awake.md) - Insomnia (krishhgg/Insomnia, MIT, Swift) is a macOS 26+ menu bar app, not the Kong Insomnia API client, that keeps a MacBook awake with the lid closed for a timed session (e.g. long AI coding-agent runs) via pmset disablesleep, with lid-close actions, battery/heat floors and a launchd recovery backstop. Source review found no telemetry; its main risk is a passwordless sudoers rule for four pmset commands usable by any process running as the user.
- [Media Editors](Technology/Tools%20And%20Utilities/Tools/Media%20Editors.md) - Resources for sound effects, GIFs, photo editing and PDF processing with Stirling PDF.
- [Online Tools](Technology/Tools%20And%20Utilities/Tools/Online%20Tools.md) - A curated collection of free web tools for image editing, diagrams, downloads, conversion, privacy, developer utilities and wallpapers.
- [OpenGym](Technology/Tools%20And%20Utilities/Tools/OpenGym.md) - openGym (DuarteSantos8/openGym, AGPL-3.0) is a self-hosted workout and body-weight tracker with passkeys, offline sync, and an optional bring-your-own AI coach; its exercise images are third-party and are not under that license.
- [Pele](Technology/Tools%20And%20Utilities/Tools/Pele.md) - Pele (obsidianmd/pele, MIT, by kepano) renders Mermaid diagrams to SVG with a small synchronous TypeScript library, no runtime dependencies and CSS-variable theming. It targets Mermaid 12.1.0 syntax with its own layout. Weeks old, 1.8.0.
- [ToolCheckMac](Technology/Tools%20And%20Utilities/Tools/ToolCheckMac.md) - ToolCheckMac (huytran1120/ToolCheckMac, MIT) is a native SwiftUI app for checking a used Mac before buying - battery, SSD SMART, MDM/DEP, Activation Lock, serial cross-check, interactive keyboard/screen/audio/camera/trackpad tests and a 0-100 score with PNG/PDF report. Source review found no network code, no sudo and read-only system commands; release builds are unsigned and not notarized.
- [Tools Notes](Technology/Tools%20And%20Utilities/Tools/Tools%20Notes.md) - Open-source business applications and a short list of terminal user-interface clients.
