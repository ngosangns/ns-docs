# Windows Tips

Windows is full of settings we may not know about, and surprising hidden features that help with basic tasks like signing in to your PC or picking an emoji to send to a friend. Some settings may not matter for everyday tasks, but one of them might make Windows friendlier after just a few minutes of tweaking.

By default, Windows turns off some settings and does not recommend changing them. In this article, though, I've picked 7 useful settings to use, plus a few features you may not realize exist.

## Sign In Faster with Sign-in Options

Even though Windows suggests it during setup, you don't have to use your account password. Windows offers sign-in options that let you log in more easily and quickly than with the account password. If you don't really care about your Microsoft account password, you can choose a PIN for faster access.

To change this setting, press Windows + i (open Windows Settings) -> choose Accounts -> Sign-in options.

You can choose any option you like as long as it is available on your machine.

## Turn Off Sticky Keys

If you're a veteran PC gamer, you've probably run into Sticky Keys. It is an accessibility feature designed for people who have difficulty holding two or more keys at once. When games require pressing Shift several times, a dialog may pop up asking whether you want to turn on Sticky Keys.

To turn it off, press Windows + i, choose Accessibility -> Keyboard -> Sticky keys -> turn off the first option.

## Dark Mode

Dark mode makes apps and websites darker, and it feels essential these days, especially if you're in a dark room where the glare from a white screen can dazzle your eyes.

By default, Windows uses Light mode. You can change it so everything in Windows switches to Dark mode.

To enable Dark mode, press Win + i, choose Personalization -> Colors -> Choose your mode -> Dark mode.

## Clipboard History

When you copy some text, a line, or a link, Windows only lets you paste the most recent thing you copied. In fact, since Windows 10, Windows can also keep a clipboard history.

You can quickly enable this feature with Windows + V -> Turn on. Once enabled, each time you copy/cut, press Win + V to open the history. Besides storing items temporarily, Windows also lets you pin copied content for later use.

## Turn Off Suggestions in the Start Menu

Windows often inserts suggested icons in Start, which can annoy some people because it clutters the list of favorite apps.

To turn off suggestions, press Win + i, choose Personalization -> Start, and turn off Show suggestions occasionally in Start.

## Windows Blue Light Filter

Whether blue light from screens seriously harms the brain is still unclear, but using features that give your screen a warmer color can help your eyes feel less tired after many hours at the PC. Windows has this built in, called Night Light!

To turn on Night Light, open Windows settings (Win + i), click System -> choose Display -> Night light. Here you can adjust how strong the yellow tint is with the slider in the Night Light settings.

## Bonus: Some Hidden Windows Features

There are other hidden time-saving features that Windows doesn't call attention to, such as:

- Switch quickly to the Desktop by pressing Windows + D.
- Send emoji with Windows + . (period).
- Select a region for a screenshot with Win + Shift + S.
- Windows + left arrow (right, up, down) snaps the working window to the left (right, top, bottom) of the screen.
- Besides Alt+Tab, you can view windows with Windows + Tab.
- Record a window on screen with Windows + G.
