# Interview - Senior Software Engineer (PHP, Javascript)

**Vị trí**: Senior Software Engineer (PHP, Javascript) - Laravel 8+

## Sườn bài phỏng vấn
1. Chào hỏi, tìm hiểu công ty, tương lai
2. Time management, tickets management
3. Refactoring skills: Đọc code bùi nhùi, refactor dễ maintain, design pattern
4. Coding Proficiency: Algorithms and data structures (failed)
5. System Design and Optimization: Thiết kế hệ thống stream multimedia, caching (Redis/Elasticsearch)
6. Version Control Discipline: Git, rebase không quen
7. Adaptability: Làm việc với codebase hiện có, khi start làm gì trước
8. Chào, bye (1h30p total)

## Câu hỏi Technical

### Frameworks & Databases
- Kinh nghiệm làm việc với JavaScript frameworks?
- Khi nào dùng MySQL hoặc MongoDB? Thích làm việc với hệ nào hơn?
- So sánh Yii2, Symfony, Laravel - framework nào tương tác database tốt? ActiveRecord, DoctrineORM, Eloquent?

### Testing
- Có bao nhiêu kiểu test? Testing Pyramid là gì?
- Developer nên viết test hay QA Team viết test?

### API
- Kinh nghiệm RESTful API?
- Đặc điểm làm RESTful API nổi bật?
- Đã ứng dụng đặc điểm nào vào app hiện tại?
- RESTful API có phải kiểu API duy nhất? Chỉ hoạt động qua HTTP?

### Frontend
- Sự khác nhau jQuery và React/Vue/Angular?
  - **Kỳ vọng**: jQuery tương tác DOM trực tiếp, các framework tương tác với virtual DOM

### Design Patterns
- Biết design pattern không? Kể tên một vài
- Tại sao singleton là anti-pattern? Điểm mạnh và yếu?

### Security
- Lỗi bảo mật thường gặp khi code?
  - **Kỳ vọng**: SQL Injection, Laravel hỗ trợ phòng chống CSRF

### CSS
- Kinh nghiệm CSS hiện đại (flexbox, grid)?

### DevOps
- OpenShift vs AWS ECS khác gì nhau?

### Architecture
- Khi nào dùng monolith, khi nào microservices? Phân tích ưu nhược điểm

## Lưu ý
- Khen Laravel giúp triển khai app nhanh, proof-of-concept
- Tuân theo convention: đặt tên Model, table đúng chuẩn
