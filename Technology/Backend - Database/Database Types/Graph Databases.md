# Graph Databases

Cơ sở dữ liệu đồ thị, lưu trữ dữ liệu dưới dạng nodes và edges.

## Đặc điểm

- Dành cho mạng xã hội hoặc truy vết
- Tối ưu cho các truy vấn về mối quan hệ

## Các Graph Database

- **Neo4j**: Graph database, ngôn ngữ Cypher, mạng xã hội, gợi ý
- **Dgraph**: Graph database phân tán, GraphQL+- - [GitHub](https://github.com/dgraph-io/dgraph)
- **JanusGraph**: Graph database phân tán
- **TigerGraph**: Graph database hiệu suất cao
