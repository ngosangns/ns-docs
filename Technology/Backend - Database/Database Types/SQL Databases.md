# SQL Databases

Cơ sở dữ liệu quan hệ sử dụng SQL.

## PostgreSQL

- ORDBMS mã nguồn mở, ACID, JSON, full-text search
- Xem chi tiết: [[PostgreSQL]]

## MySQL

- Hệ quản trị cơ sở dữ liệu quan hệ phổ biến
- Xem chi tiết: [[MySQL]]

## TiDB

- NewSQL phân tán, tương thích MySQL, horizontal scaling
- Thường dùng cho ecommerce, bank

## ClickHouse

- Columnar database, OLAP, hiệu suất cao
- OLAP - Online Analytical Processing
- [GitHub](https://github.com/ClickHouse/ClickHouse)
