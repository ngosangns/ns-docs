# GraphQL

Ngôn ngữ truy vấn cho API, runtime phía server.

## Đặc điểm

- Client yêu cầu chính xác dữ liệu cần thiết
- Một endpoint duy nhất, hệ thống kiểu mạnh

## Tools

- **Altair**: GraphQL client - [GitHub](https://github.com/altair-graphql/altair)

## Frameworks

- **Hasura**: Tự động tạo GraphQL API từ database - [Website](https://hasura.io/)

## Clients

- **Relay**: Framework JavaScript của Facebook để xây dựng ứng dụng React sử dụng GraphQL - [GitHub](https://github.com/facebook/relay)
