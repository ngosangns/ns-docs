# Full-Text Search

- Sử dụng inverted index
- Hỗ trợ tìm kiếm tự nhiên, cụm từ, boolean
- Bỏ qua stop words, hỗ trợ stemming
- Xếp hạng theo relevance scoring
- MySQL: Hỗ trợ bởi MyISAM và InnoDB (từ 5.6)
