# Web And Desktop Frameworks

- https://github.com/voidzero-dev/vite-plus — Unified toolchain and entry point for web development; manages runtime, package manager, and brings Vite, Vitest, Rolldown, tsdown, Oxlint, and Oxfmt together with a built-in task runner.
- https://github.com/cloudflare/vinext — Reimplements the Next.js API surface on Vite; deployable to Cloudflare Workers and other platforms.
- https://github.com/blackboardsh/electrobun — Cross-platform desktop app framework using TypeScript, Bun, and Zig with tiny ~12MB bundles.
- https://github.com/AkkalDhami/servercn — Backend component registry for Node.js & TypeScript; Shadcn-style CLI for scaffolding production-ready backend code.
- https://github.com/carbon-design-system/carbon — IBM's open-source design system with React, Web Components, styles, icons, and themes.
- https://github.com/Curbob/LobsterBoard — Self-hosted drag-and-drop dashboard builder with 60+ widgets, template gallery, and zero cloud dependencies.
- https://github.com/lochie/web-haptics — Haptic feedback library for the mobile web; supports React, Vue, and Svelte.
- https://github.com/0xGF/boneyard — Boneyard (`boneyard-js`): auto-generates pixel-perfect skeleton loading screens from your real UI, with no hand-measured placeholders. On the web, a headless-browser CLI (with watch mode or a Vite plugin) visits the app, finds each `<Skeleton>` wrapper, and snapshots its layout at breakpoints (375/768/1280px by default); in React Native the component auto-scans in dev by walking the fiber tree via UIManager. Both output a shared `.bones.json` format. Supports React, Preact, Vue, Svelte 5, Angular, and React Native; pulse/shimmer/solid animations, stagger/transitions, `darkColor` for dark mode, and `fixture` data for build-time extraction. MIT; demo at https://boneyard.vercel.app/
- https://github.com/macaly/almostnode — Lightweight browser-native Node.js runtime; install npm packages and run Vite/Next.js dev servers entirely in the browser.
- https://github.com/Avaiga/taipy — Python framework for turning data and AI algorithms into production-ready web applications without leaving Python.
- https://github.com/typv/nest-turbo-starter — NestJS monorepo starter kit for building scalable microservices with Turborepo and pnpm.
- https://github.com/facebook/astryx — Open-source, fully customizable, agent-ready React design system from Meta; 150+ TypeScript components, theme-as-CSS-variables system, 7 ready-made themes, and a CLI so people and AI assistants build the same way from the same reference.
- https://21st.dev/ — Community registry of 12,000+ production-ready React/Tailwind CSS components, templates, and themes built by design engineers; live preview, one-command install that copies code into your repo (no dependency lock-in), aimed at both developers and AI coding agents.
- https://github.com/vercel-labs/native — Vercel Labs experiment: toolkit for building native desktop apps with a declarative `.native` markup and TypeScript compiled to native code (Zig engine); renders every pixel directly to real OS windows with no browser/WebView/JS runtime in the binary.
- https://github.com/TheOrcDev/shadscan — Deterministic UI audits for shadcn/ui apps, runnable from the terminal, CI, or an AI agent.
- https://flutterinit.com/ — CLI (`npx create-flutterinit`) to scaffold a full Flutter app: choice of state management (Riverpod/Bloc), routing (GoRouter), architecture (Clean/MVVM/MVC), and integrations (Supabase, Firebase, Dio); also emits AGENTS.md/DESIGN.md/.cursorrules for AI-assisted coding. Open source.
- https://nativephp.com/ — Build native desktop (macOS/Windows/Linux via Electron) and mobile (iOS/Android via Swift/Kotlin shells) apps from a Laravel/PHP codebase; bundles PHP with the app and exposes native APIs (menus, notifications, filesystem, SQLite) to Blade/Vue/React front-ends.
- https://github.com/NativePHP/jump — Companion iOS/Android app for NativePHP mobile development: scan a QR code to stream and hot-reload your Laravel (PHP 8.4+/Laravel 13.x) app straight onto a physical phone over LAN (mDNS discovery), no Xcode/Android Studio build step required; renders native UI via SwiftUI/Jetpack Compose and exposes device APIs (camera, biometrics, push, geolocation, scanner, media player) from Blade/native-ui components. New/niche (MIT, ~8 stars as of Sept 2026).
- https://namethatui.com/ — Visual dictionary for naming UI elements; describe a component in plain language ("the dots under the slideshow") and get its official name, API/class references, and ready-to-use coding prompts. Covers 80+ macOS (AppKit/SwiftUI) and 50+ web elements with cross-platform translation tables, plus a companion "Name That Vibe" section for design tokens/aesthetics. Useful for bridging design/dev vocabulary and writing more precise AI coding prompts.
- https://github.com/longbridge/gpui-kit — Rust component library for GPUI (Zed's GPU-accelerated Rust UI framework); 75+ components across three layers (`gpui-component` for styled controls, `gpui-base` for unstyled behavior/infra, `gpui-shell` for a JS runtime), GPU-accelerated rendering targeting 120 FPS, virtual-scrolling data tables, a built-in code editor (Tree-sitter, LSP diagnostics, 200K+ lines), AccessKit accessibility, WASM target, and headless UI testing. Powers Longbridge Pro in production. macOS/Windows/Linux.
- https://github.com/zed-industries/awesome-gpui — Curated list of ~150 projects built with or for GPUI (Zed's Rust UI framework, gpui.rs), grouped into dev tools (editors, DB clients, API testers, terminal emulators, AI coding agent UIs), productivity apps, media apps, system utilities, and libraries; entries tagged by activity (active/quiet/dormant/archived) and star count — a good discovery point for GPUI-based desktop apps and component libraries.
