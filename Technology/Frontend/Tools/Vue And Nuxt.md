# Vue And Nuxt

## Vue And Nuxt Tips

### Validating

- Validating multiple components: use `Array.every()` to check that all validations pass
- Showing/hiding the "Save changes" button:
  - At least one property changed: `Array.some()`
  - All validations pass: `Array.every()`

### Reactive

- Class Component Decorator - making a variable non-reactive:
  - Declare the variable inside a method
  - Declare the property without an initial value and only assign it inside a method

## Libraries And Tools

### Form

- **Form Validation**:
  - **Vee-validate**: powerful, easy to use, well integrated (medium and large projects)
  - **Vuelidate-next**: simple, model-based (small and medium projects)
  - **vue-tiny-validate**: compact (small projects)
  - **vorms**: another option
- **Form Generator/Builder**:
  - **vue-flow-form**: form flows (wizards, surveys)
