# Concepts

- [Audiocn](Technology/Frontend/Tools/Audiocn.md) - audiocn (audiocn/ui, MIT, by OrcDev and fortysevenfx) is a shadcn/ui registry of copy-and-own React audio components - about two dozen components (level meters, spectrum and waveform visualizers, faders, knobs, channel strips, a mixer, a player, sound pads), 6 blocks and 18 Web Audio hooks, built on Base UI and Tailwind v4 and themed by shadcn tokens. Not an npm package; installed with npx shadcn add @audiocn/<item>. Launched 2026-10-02.
- [Bklit TanStack Charts](Technology/Frontend/Tools/Bklit%20TanStack%20Charts.md) - bklit-tanstack-charts (toomingos/bklit-tanstack-charts-migration, MIT) rebuilds bklit-ui chart components on TanStack Charts 1.1 and keeps the bklit compound API. Checked 4 November 2026 on main 9bdabac. npm latest is 0.1.1, published 1 November 2026, with peers React 19 and @tanstack/charts ~1.1.0. The README says this is not a pull request to bklit/bklit-ui. GitHub's license API returns NOASSERTION because the LICENSE file appends a derived-work notice after the MIT text.
- [CSS Tools](Technology/Frontend/Tools/CSS%20Tools.md) - A curated list of CSS libraries, linters, animation libraries, build tools, zero-runtime CSS-in-JS options, themes and icon sets.
- [Ely GPUI](Technology/Frontend/Tools/Ely%20GPUI.md) - Ely (elygpui.com) is an MIT component library for GPUI, the Rust UI framework behind Zed, not a GPU cloud. It claims about 1,279 components in 44 chapters with a live WebAssembly gallery. It is a weeks-old solo project, git-only, pinned to gpui-pre 0.3.8, and tested only on macOS.
- [Glimm](Technology/Frontend/Tools/Glimm.md) - glimm (npm glimm 0.3.1, MIT, Noman Ijaz) draws a WebGL band across the page during a route change, with a vanilla core and React and Next.js adapters. Checked 4 November 2026. The homepage says the library is under 10 KB. Published dist/index.js is 68514 bytes and gzip at level 9 is 18231 bytes. The repository URL in the npm document, github.com/nomanjack/glimm, returned HTTP 404. The homepage says Next 13 or newer, while peerDependencies set next to >=14.
- [Gr8r Studio](Technology/Frontend/Tools/Gr8r%20Studio.md) - Gr8r Studio (gr8rstudio/gr8r-studio) is a project management UI built with Vite and plain JavaScript ES modules, with no framework and no runtime dependency. It is a front-end-only demo with seeded data in localStorage and a mock login, not a working backend. No license file; three commits, all on 2026-10-07.
- [Hallmark](Technology/Frontend/Tools/Hallmark.md) - Hallmark (Nutlope/hallmark, MIT, v2.0.0, made by Together AI) is a design skill for Claude Code, Codex, Cursor and OpenCode that builds new pages from one of 48 dealt themes under a non-negotiable Floor of design rules, then lints the result in a real browser with sloplint --render and a fresh-context review. 35.7k stars, 1.9k forks, 62 open issues at check time.
- [Histoire](Technology/Frontend/Tools/Histoire.md) - Histoire (histoire-dev/histoire, MIT) is a Vite-native story book for developing and documenting components in isolation, the Vite answer to Storybook, led by Guillaume Chau (Akryum). npm latest is 1.0.0-beta.1 (Jan 2026) with Vue 3 and Svelte plugins; main also documents React, Nuxt, SvelteKit, and MCP tools not yet in a release.
- [Looseleaf](Technology/Frontend/Tools/Looseleaf.md) - Looseleaf (kevintngo/looseleaf, MIT) is a shadcn/ui-compatible React component library where every surface is paper and every line is a seeded SVG drawing — 123 components, 61 blocks and a static shadcn registry, installed as source rather than a dependency.
- [MyGo](Technology/Frontend/Tools/MyGo.md) - MyGo (egoist/mygo, MIT) builds desktop apps in pure Go without cgo. Each window shows either a web page in the system webview, with a TypeScript client generated from Go, or native UI drawn by MyGo on the GPU. The latest release is v0.6.2 and it needs Go 1.27+.
- [Prestige UI](Technology/Frontend/Tools/Prestige%20UI.md) - Prestige UI (vora-aryan/Prestige-UI, MIT) is a shadcn registry of animated React components for Tailwind CSS v4 and Motion. Checked 4 November 2026 on main da6c605. The README lists 20 free items in the repo. prestigeui.com/pricing says those stay free and All Access is a one-time $49 launch price through 5 November 2026, paid with Polar. This check did not run the shadcn CLI or buy a license.
- [NSH](Technology/Frontend/Tools/NSH.md) - NSH (Native Shell, longbridge/nsh, Apache-2.0) is a Rust engine that renders TSX or Rust UI with each platform's own native views, built for AI-generated screens and signed plugins delivered to a host app at run time. Weeks old, v0.1.1.
- [OrganUI](Technology/Frontend/Tools/OrganUI.md) - OrganUI (organui/organui, MIT) is a shadcn-compatible registry of editable React components for healthcare and life sciences. It has 42 three.js organ models, a molecule viewer, a DNA helix, an ECG trace, a dermatome map, a CT/MRI slice viewer and more, with explicit "not for clinical use" disclaimers. Weeks old, v0.4.0.
- [React Next](Technology/Frontend/Tools/React%20Next.md) - A curated reference for the React and Next.js ecosystem covering hooks, optimization, design systems, rendering patterns, libraries and a developer roadmap.
- [SakaniUI](Technology/Frontend/Tools/SakaniUI.md) - SakaniUI (samzydd/Sakaniui, npm @sakaniui/react 0.8.5, MIT) is a single-author React 19 design system built 1:1 from a Figma file - 114+ components, 42 copy-and-edit blocks, three-layer CSS-variable tokens, light/dark plus a Solid/Glass/Liquid surface axis with SVG-refraction liquid glass (Chromium only), Tabler icons and Recharts charts. About 3 months old, 63 stars.
- [slide.ng](Technology/Frontend/Tools/Slide%20Ng.md) - slide.ng (slide-ng/slide.ng, npm @slide-ng/core 1.0.0, MIT, by Erkam Yaman) is a Slidev port for Angular. One slides.md becomes one standalone Angular component per slide, with real Angular template syntax inside, Slidev's layouts, clicks, presenter view, Shiki/Magic Move/Monaco/KaTeX/Mermaid, export to PDF/PNG/PPTX (pictures only)/Markdown, offline builds, themes, an MCP server and an agent skill. Created 2026-10-16, about 100 stars, almost all commits by one author.
- [TanStack DB](Technology/Frontend/Tools/TanStack%20DB.md) - TanStack DB (TanStack/db, MIT, npm @tanstack/db 1.0.0-rc.1.3) is a client store that keeps typed collections, live queries, and optimistic mutations in the app process. Checked 4 November 2026 on main 8feab6ea. The README still marks the project beta. docs/overview.md says live queries update through the d2ts differential-dataflow library, and the 0.7 ms figure there was not remeasured.
- [TanStack Hotkeys](Technology/Frontend/Tools/TanStack%20Hotkeys.md) - TanStack Hotkeys (@tanstack/hotkeys 0.18.0, MIT, TanStack) is a type-safe keyboard-shortcut library for ten frameworks plus vanilla JS - Mod, Vim-style sequences, scopes, app hotkeys, recording, key-state tracking and devtools - with Agent Skills shipped inside the npm packages. Still beta at 0.x.
- [Text Editor React](Technology/Frontend/Tools/Text%20Editor%20React.md) - Text Editor React (HuyPhan1232203/Text-editor-react, MIT, Phan Nhật Huy) is a Word-like TipTap 3 editor built with React 19 - real A4 pages from a published pagination extension, tables split across pages, comments, Yjs-over-WebRTC sharing with the key in the URL fragment, and PDF export through the print dialog or a Puppeteer backend.
- [Vue And Nuxt](Technology/Frontend/Tools/Vue%20And%20Nuxt.md) - Tips, libraries, UI kits, testing tools and templates for the Vue and Nuxt ecosystem.
- [Vue TermUI](Technology/Frontend/Tools/Vue%20TermUI.md) - Vue TermUI (vue-terminal/vue-termui, MIT, posva) is a Vue 3 custom renderer for terminal apps on OpenTUI's native Zig engine — flexbox layout, forms, focus, and a Vite plugin with in-terminal HMR; ground-up rewrite from the old Yoga-based stack. npm vue-termui 0.3.0.
- [Web And Desktop Frameworks](Technology/Frontend/Tools/Web%20And%20Desktop%20Frameworks.md) - A curated list of newer frameworks, toolchains and scaffolding tools for web (frontend and backend) and desktop apps.
