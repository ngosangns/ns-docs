- **animate.css**: Thư viện hoạt ảnh

## Tính năng CSS nâng cao

### CSS Anchor Positioning

- Định vị phần tử tương đối so với phần tử neo
- **Thuộc tính**: `anchor-name`, `anchor-position`, `@position-fallback`
- **Ví dụ**: `anchor-name: --my-anchor; position: anchor(--my-anchor);`

### CSS Scroll-Driven Animations

- Hoạt ảnh điều khiển bởi vị trí cuộn
- **Thành phần**: `animation-timeline`, `scroll()`, `view()`
- **Ví dụ**: `animation-timeline: scroll(); animation-range: 0 100vh;`

### light-dark()

- Chuyển đổi giữa chế độ sáng và tối
- **Ví dụ**: `background-color: light-dark(#fff, #000);`
