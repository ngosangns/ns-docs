# VPN Proxy Firewall

## Services

- Xray-core - Set up and use proxy protocols: https://github.com/XTLS/Xray-core
- WireGuard
  - OpenVPN
- pfsense - Firewall / Proxy / DHCP / VPN / DNS: https://github.com/pfsense/pfsense
- SafeLine - self-hosted WAF (Web Application Firewall) / reverse proxy to protect your web apps from attacks and exploits: https://github.com/chaitin/SafeLine
- **headscale** - Open source, self-hosted implementation of the Tailscale control server. Lets you set up a WireGuard-based virtual private network (VPN) without depending on Tailscale's cloud service: https://github.com/juanfont/headscale
