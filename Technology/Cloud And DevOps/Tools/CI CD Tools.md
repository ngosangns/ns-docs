# CI CD Tools

## GitHub Actions

- **GitHub Actions**: A software development workflow automation platform built into GitHub.
- **Reusable Workflows**: Reusing workflows in GitHub Actions - [Viblo](https://viblo.asia/p/reusable-workflows-tai-su-dung-workflows-trong-github-actions-zOQJwowbJMP)

## General CI/CD Tools

- **Woodpecker**: A simple yet powerful CI/CD tool with high extensibility, forked from Drone CI - [GitHub](https://github.com/woodpecker-ci/woodpecker) #CI #CD #cicd
- **GitLab CI/CD**: A powerful CI/CD system built into GitLab, supporting complex pipelines and good Kubernetes integration.

## Security & Code Quality in CI/CD

- **Semgrep**: A fast, open-source static application security testing (SAST) tool supporting many languages. It detects security bugs, misconfigurations, and dangerous code patterns.
- **SonarQube**: A platform for automated source code quality inspection that detects bugs, security vulnerabilities, and code smells.

## Pipeline Examples & Blueprints

- **Node-EKS-CICD**: A sample CI/CD pipeline for a Node.js application on Amazon EKS.
  - **Technologies**: GitLab CI, Docker, Kubernetes, Helm, Prometheus, Grafana.
  - **Features**: Security scanning with Semgrep, quality analysis with SonarQube, automatic deployment to EKS.
  - [Source](https://gitlab.com/HlaliMedAmine/node-aks-cicd)
