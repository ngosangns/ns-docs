# Concepts

- [e2e](Technology/Testing/Tools/E2e.md) - e2e (npm e2e 0.18.0, tester-army/e2e, Apache-2.0) is TesterArmy's pre-1.0 web and mobile runner that mixes natural-language agent steps with locator assertions, using Playwright in the browser and agent-device on devices; npm versions 0.0.x are the older willscott/e2e OpenPGP library.
- [Testing Tools](Technology/Testing/Tools/Testing%20Tools.md) - A curated list of tools for API and integration testing, load testing, architecture checks, browser testing and dependency analysis.
