# 4. PDF

- https://github.com/Stirling-Tools/stirling-pdf — Stirling PDF: nền tảng PDF mã nguồn mở (open-core). Chạy app desktop, giao diện trình duyệt, hoặc self-host (`docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf`). Hơn 50 công cụ: sửa, gộp, tách, ký, redact, chuyển đổi, OCR, nén; có workflow không cần code và API riêng, file không phải gửi ra dịch vụ ngoài. Tài liệu: https://docs.stirlingpdf.com
