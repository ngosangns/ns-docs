# Concepts

- [MongoDB](Technology/Backend%20And%20Database/Tools/MongoDB.md) - Guide to MongoDB, the document-oriented NoSQL database, covering its data model, CRUD operations, indexing, aggregation, replication, sharding, and best practices.
- [MySQL](Technology/Backend%20And%20Database/Tools/MySQL.md) - Guide to MySQL, the popular open-source RDBMS, covering storage engines, data types, CRUD, indexing, views, procedures, triggers, replication, and best practices.
- [PGX](Technology/Backend%20And%20Database/Tools/PGX.md) - PGX (pgrundev/pgx, AGPL-3.0) is a Rust runtime that serves hundreds to thousands of isolated Postgres 18.6-compatible databases from one process via mint-on-connect and ZFS copy-on-write branches, built for CI, previews and agent sandboxes rather than production.
- [PostgreSQL](Technology/Backend%20And%20Database/Tools/PostgreSQL.md) - Guide to PostgreSQL, the extensible open-source RDBMS, covering data types, JSON/JSONB, arrays, full-text search, index types, window functions, CTEs, and best practices.
- [Redis](Technology/Backend%20And%20Database/Tools/Redis.md) - Guide to Redis, the in-memory data structure store used as a database, cache, and message broker, covering its use cases, data types, persistence, and best practices.
