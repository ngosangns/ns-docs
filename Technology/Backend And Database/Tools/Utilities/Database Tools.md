# Database Tools

Tools that help when working with databases.

## Development & Setup

- **Docker Compose**: Set up a development environment with many types of databases - [Reference](https://viblo.asia/p/docker-compose-cho-cac-loai-database-pho-bien-qPoL78N1Vvk)

## Query Builders & Code Generation

- **sqlc**: Auto-generates boilerplate SQL queries, type-safe - [Website](https://sqlc.dev)
- **AskDB**: Scans a database and generates queries with an LLM - [GitHub](https://github.com/phanxuanquang/AskDB)
- **jason** (aurijs/jason): A tool that simplifies database management and reduces the complexity of handling data - [GitHub](https://github.com/aurijs/jason)
- **Dingo**: Open-source distributed system providing services and tools for managing and processing big data - [GitHub](https://github.com/MigoXLab/dingo)

## Online Tools

- **RunSQL**: Online environment for running SQL queries on database systems such as MySQL, PostgreSQL, and SQL Server
  - Supports SQL practice and learning
  - Intuitive web interface for writing and running queries
  - Website: https://runsql.com/ #SQL #online #database #practice
