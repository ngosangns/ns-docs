# Vector Databases

Purpose-built to store, manage, and search vector embeddings.

The function named here is similarity search. It uses cosine similarity and Euclidean distance. Embeddings are what that search runs on. Store, manage, and search are the three jobs in the purpose line.

The applications are recommendation systems, semantic search, image recognition, anomaly detection, and generative AI. Those five are the whole application list in this note.

A video is linked under resources. The title in the note is Vector Database Video. Supporting tools are linked as Database Tools and as AI Vector Databases. NoSQL Databases and Full Text Search sit in the see also line with AI Vector Databases.

## Functions

- Similarity search based on cosine similarity and Euclidean distance

## Applications

- Recommendation systems
- Semantic search
- Image recognition
- Anomaly detection
- Generative AI
