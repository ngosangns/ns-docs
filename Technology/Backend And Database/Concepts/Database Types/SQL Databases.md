# SQL Databases

Relational databases that use SQL.

## PostgreSQL

- Open-source ORDBMS with ACID, JSON, and full-text search
- See details: [PostgreSQL](/Technology/Backend And Database/Tools/PostgreSQL)

## MySQL

- A popular relational database management system
- See details: [MySQL](/Technology/Backend And Database/Tools/MySQL)

## TiDB

- Distributed NewSQL database, MySQL-compatible, with horizontal scaling
- Commonly used for e-commerce and banking

## ClickHouse

- Columnar database for OLAP with high performance
- OLAP - Online Analytical Processing
- [GitHub](https://github.com/ClickHouse/ClickHouse)
