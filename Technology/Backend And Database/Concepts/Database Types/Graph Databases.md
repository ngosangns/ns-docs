# Graph Databases

Graph databases store data as nodes and edges.

## Characteristics

- Built for social networks and tracing
- Optimized for relationship queries

## Graph Databases

- **Neo4j**: Graph database with the Cypher query language; used for social networks and recommendations
- **Dgraph**: Distributed graph database, GraphQL+- - [GitHub](https://github.com/dgraph-io/dgraph)
- **JanusGraph**: Distributed graph database
- **TigerGraph**: High-performance graph database
