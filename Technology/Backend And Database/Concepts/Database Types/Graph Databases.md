# Graph Databases

Graph databases store data as nodes and edges.

They are built for social networks and for tracing. They are optimized for relationship queries. Social networks and tracing are the uses named for this kind of database.

Neo4j is a graph database with the Cypher query language. It is used for social networks and recommendations. Recommendations and Cypher are named only for Neo4j. Dgraph is a distributed graph database, and the note ties it to GraphQL+-. JanusGraph is also a distributed graph database. TigerGraph is a high-performance graph database. JanusGraph and Dgraph are both called distributed.

NoSQL Databases and SQL Databases are the related notes.

## Characteristics

- Built for social networks and tracing
- Optimized for relationship queries

## Graph Databases

- **Neo4j**: Graph database with the Cypher query language; used for social networks and recommendations
- **Dgraph**: Distributed graph database, GraphQL+- - [GitHub](https://github.com/dgraph-io/dgraph)
- **JanusGraph**: Distributed graph database
- **TigerGraph**: High-performance graph database
