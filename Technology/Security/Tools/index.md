# Concepts

- [Authorized Artifact Auditor](Technology/Security/Tools/Authorized%20Artifact%20Auditor.md) - ptn1411/skill ("Authorized Artifact Auditor", Python, no license file) is a pack of about 35 agent skills plus Python CLIs for reverse engineering and auditing software you own - fingerprinting, unpacking, decompiling, web and network recon, SBOM, CVE lookup. The README and MASTER_POLICY.md say defensive use only, but several skills in the repo (master-unlock, dotnet-keygen, binary-patcher, frida-hooker) are written as bypass and keygen tools. Read before installing.
- [Awesome Reverse Engineered](Technology/Security/Tools/Awesome%20Reverse%20Engineered.md) - alexgaoth/awesome-reverse-engineered is a searchable index of about 12,900 open-source projects that exist because someone reverse engineered a closed app, API, device, protocol, file format, game or AI tool, with a website, a JSON dataset (CC0) and an agent skill that searches it. Use it to check whether the work is already done before reverse engineering something yourself.
- [RedAmon](Technology/Security/Tools/RedAmon.md) - RedAmon (samugit83/redamon, MIT) is a self-hosted Docker penetration-testing framework that maps an authorized target into a Neo4j graph, runs an agent from a Kali sandbox behind approval gates, and can open a GitHub pull request for a fix.
- [Security Tools](Technology/Security/Tools/Security%20Tools.md) - A curated list of tools for secret management, vulnerability scanning, cryptography, security analytics, pentesting and PII detection.
