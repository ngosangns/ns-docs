# AI - Machine Learning

## Dynamic Ride Pricing System

- **Repository**: https://github.com/200lab-Education/dynamic-ride-pricing-system
- **Description**: Hệ thống định giá động cho ứng dụng ride-hailing, sử dụng Machine Learning và nhiều yếu tố thực tế để tối ưu giá cả theo thời gian thực
- **Features**:
  - Smart Pricing: Dự đoán giá cơ bản dựa trên khoảng cách, thời gian, loại xe
  - Real-time Factors: Điều chỉnh giá dựa trên thời tiết, tắc đường, cung-cầu
  - API Integration: RESTful API cho ứng dụng thực tế
  - Analytics: Dashboard Streamlit để phân tích và mô phỏng
  - Dynamic Price Adjustments:
    - Supply-Demand: ±15%
    - Weather: +5-10%
    - Traffic Congestion: +3-12%
    - Customer Loyalty: -5-15%
- **Tech Stack**: Python, Random Forest (ML), Streamlit, REST API
- **License**: MIT
- **Use Cases**: Ride-hailing pricing, dynamic pricing systems, supply-demand optimization, real-time price calculation
