# Website Builder

## Framely

- **Repository**: https://github.com/belastrittmatter/Framely
- **Description**: Open-source, lightweight, multi-tenant drag-and-drop website editor for modern web applications, powered by Next.js
- **Tech Stack**:
  - Next.js
  - Tailwind CSS
  - Shadcn UI
  - Prisma & MySQL
  - Clerk Authentication
  - Umami Analytics
- **Features**:
  - ✅ Authentication (Clerk)
  - ✅ Dashboard (create and view sites)
  - ✅ Backend logic for website builder
  - ✅ Drag-and-drop website builder
  - ✅ Multi-tenancy with subdomains
  - 🚧 Generated CSS preview (coming soon)
  - 🚧 Optimized NextJS exports (coming soon)
  - 🚧 SEO optimization (coming soon)
  - 🚧 Dynamic OG cards (coming soon)
  - 🚧 Image uploads (coming soon)
  - 🚧 Site analytics (coming soon)
  - 🚧 TailwindCSS support (coming soon)
  - 🚧 Custom domain support (coming soon)
- **Demo**: https://framely.site
- **License**: MIT
