# AI Agents Resources

## Awesome AI Agents

- **Repository**: https://github.com/e2b-dev/awesome-ai-agents
- **Description**: Curated list of over 150 AI agent frameworks and resources, categorized to assist developers in finding tools for various applications
- **Categories**:
  - Coding assistants
  - Productivity agents
  - AI agent frameworks
  - Development resources
- **Use Cases**: Building AI-driven applications, finding AI agent tools and frameworks

## LangGraph

- **Repository**: https://github.com/langchain-ai/langgraph
- **Description**: Framework for building stateful, multi-actor applications with LLMs. Enables building robust language agents as graphs
- **Features**:
  - Stateful agent workflows
  - Graph-based architecture
  - Multi-actor applications
  - Built on LangChain
  - Supports complex NLP applications
- **Use Cases**: Building conversational AI, multi-step reasoning agents, complex LLM workflows

## Tabby

- **Repository**: https://github.com/TabbyML/tabby
- **Description**: Self-hosted AI coding assistant that provides code completion and suggestions
- **Features**:
  - Self-hostable
  - Code completion
  - Privacy-focused (runs on your infrastructure)
  - Supports multiple programming languages
- **Use Cases**: AI-powered code completion, developer productivity tools
