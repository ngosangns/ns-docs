# Algorithms & Optimization

## Google OR-Tools

- **Repository**: https://github.com/google/or-tools
- **Description**: Google's open-source optimization tools for solving complex optimization problems
- **Features**:
  - Linear programming
  - Constraint programming
  - Vehicle routing
  - Graph algorithms
  - Bin packing
  - Scheduling algorithms
  - Multiple programming language support (C++, Python, Java, C#)
- **Use Cases**: Operations research, logistics optimization, resource allocation, scheduling problems
- **License**: Apache-2.0
