# Database Tools

## NocoDB

- **Repository**: https://github.com/nocodb/nocodb
- **Description**: Open-source Airtable alternative that turns any SQL database into a smart spreadsheet
- **Features**:
  - Convert SQL databases to spreadsheets
  - Visual database management
  - REST and GraphQL APIs
  - Self-hostable
  - Collaborative workspace
  - Multiple database support (MySQL, PostgreSQL, SQLite, etc.)
- **Use Cases**: Database management, building admin panels, no-code database interfaces

## M3

- **Repository**: https://github.com/m3db/m3
- **Description**: Open-source distributed time series database and query engine, designed for scalability and high performance
- **Features**:
  - Time series data storage
  - High-performance queries
  - Distributed architecture
  - Prometheus-compatible
  - Horizontal scaling
  - Efficient compression
- **Use Cases**: Metrics storage, monitoring systems, time series analytics
