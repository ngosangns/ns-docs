# AI Copilot Framework

## CopilotKit

- **Repository**: https://github.com/CopilotKit/CopilotKit
- **Description**: Cung cấp giao diện người dùng React và hạ tầng tinh gọn cho các AI Copilot, chatbot AI và các tác nhân AI trong ứng dụng
- **Features**:
  - Cung cấp các thành phần UI có thể tùy chỉnh hoặc sử dụng API không giao diện để tích hợp AI vào ứng dụng
  - Hỗ trợ tích hợp với các framework như React, Next.js và AGUI
  - Cung cấp các hook như `useAgent` để kiểm soát kết nối với tác nhân AI
  - Hỗ trợ các trường hợp sử dụng thực tế như triển khai trợ lý AI tích hợp sâu vào ứng dụng
  - Dễ dàng tích hợp với CLI đơn giản
  - Bảo mật tích hợp sẵn với bảo vệ chống chèn lệnh nhắc (prompt injection protection)
  - Mã nguồn mở, minh bạch và được cộng đồng đóng góp
- **Use Cases**:
  - Xây dựng AI Copilot trong ứng dụng
  - Tích hợp chatbot AI vào web applications
  - Tạo AI agents với giao diện người dùng
  - Building applications với CopilotKit và các framework khác như Microsoft Agent Framework và Mastra
- **Resources**:
  - Cung cấp các mẫu mã và hướng dẫn để xây dựng ứng dụng
  - Cộng đồng hỗ trợ thông qua Discord và tài liệu chi tiết
- **Website**: https://github.com/CopilotKit/CopilotKit
