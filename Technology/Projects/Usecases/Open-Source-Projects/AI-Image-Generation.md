# AI - Image Generation

## SDVN Comfy Node

- **Repository**: https://github.com/StableDiffusionVN/SDVN_Comfy_node
- **Description**: Bộ node thông minh cho ComfyUI, hỗ trợ các cách sử dụng dễ dàng và tiện lợi hơn cho việc tạo ảnh với AI
- **Features**:
  - Base Nodes: Load checkpoint/LoRA, Load images từ folder/URL/Pinterest/Instagram
  - Image processing: Upscale, resize, crop, mask tools
  - Download helpers: Tự động download models từ Civitai và HuggingFace
  - Merge: Smart model merging với block weight control
  - Creative nodes: IPAdapter weight, Translate, Any show, Switch nodes
  - API integration: Gemini, OpenAI, HuggingFace, Deepseek
  - Preset system: Auto Generate node với auto parameter calculation
  - Mask tools: YOLO Seg Mask, Mask Regions, Crop Inpaint
  - Metadata tools: Lora info, Model info editor, Image info
  - Support: SD15, SDXL, Flux models
  - Auto model-type detection (CFG/sampler/scheduler)
  - Translation và Dynamic prompt support
  - ControlNet/Apply Style presets
- **Tech Stack**: Python, ComfyUI
- **License**: MIT
- **Use Cases**: AI image generation workflows, automated image processing, model management, creative workflows
