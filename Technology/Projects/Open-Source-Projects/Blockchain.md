# Blockchain

## Polkadot SDK

- **Repository**: https://github.com/paritytech/polkadot-sdk
- **Description**: Complete development toolkit for building blockchains and applications on Polkadot network
- **Features**:
  - Substrate framework for building blockchains
  - Polkadot runtime
  - Parachain development tools
  - Cross-chain communication
  - Modular blockchain architecture
- **Use Cases**: Building custom blockchains, parachains, blockchain applications
