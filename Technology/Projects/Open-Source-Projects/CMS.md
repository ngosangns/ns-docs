# Content Management System (CMS)

## Payload CMS

- **Repository**: https://github.com/payloadcms/payload
- **Description**: Open-source Next.js fullstack framework providing TypeScript backend and admin panel out of the box. Can be used as a headless CMS or to build powerful applications
- **Features**:
  - TypeScript-first
  - Self-hosted
  - Headless CMS
  - Admin panel included
  - GraphQL and REST APIs
  - Authentication & authorization
  - File uploads
  - Localization support
  - Extensible with hooks and plugins
- **Tech Stack**: Next.js, TypeScript, MongoDB/PostgreSQL
- **License**: MIT
- **Website**: https://payloadcms.com
