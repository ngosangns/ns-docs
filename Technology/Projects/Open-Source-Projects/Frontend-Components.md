# Frontend Components

## re-resizable

- **Repository**: https://github.com/bokuweb/re-resizable
- **Description**: Component React cho phép resize các phần tử, hỗ trợ kéo thả để thay đổi kích thước
- **Features**:
  - Hỗ trợ resize theo 8 hướng (top, right, bottom, left, và các góc)
  - Tùy chỉnh min/max width và height
  - Snap to grid và snap to specific values
  - Lock aspect ratio
  - Custom resize handles và styles
  - Hỗ trợ touch events cho mobile
  - Bounds constraints (window, parent, hoặc element)
  - Grid và grid gap support
  - Resize ratio control
- **Tech Stack**: React, TypeScript
- **License**: MIT
- **Stars**: 2.7k+
- **Use Cases**: Dashboard layouts, resizable panels, drag-and-drop interfaces
