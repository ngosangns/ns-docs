# ERP Platform

## AureusERP

- **Repository**: https://github.com/aureuserp/aureuserp
- **Description**: Free and open-source Enterprise Resource Planning (ERP) solution designed for Small and Medium Enterprises (SMEs) and large-scale enterprises
- **Tech Stack**:
  - Laravel 11.x
  - FilamentPHP 4.x
  - PHP 8.2+
  - MySQL 8.0+ / SQLite
  - TailwindCSS
- **Features**:
  - Highly modular design (core plugins + installable plugins)
  - Role-based access control (Filament Shield)
  - Modern admin panel with FilamentPHP
  - Extensible architecture
  - One-command installation (`php artisan erp:install`)
- **Core Plugins**: Analytics, Chatter, Fields, Security, Support, Table View
- **Installable Plugins**: Accounts, Contacts, Employees, Inventories, Invoices, Partners, Payments, Products, Projects, Purchases, Recruitments, Sales, Timeoffs, Timesheet, Website, Blogs
- **Website**: https://aureuserp.com
- **License**: MIT
