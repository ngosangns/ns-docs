# Development Documentation

The C4 model is an easy to learn, developer friendly approach to software architecture diagramming. Its official website is written by the creator, Simon Brown. The model uses a set of hierarchical abstractions. Those abstractions are software systems, containers, components, and code. It also uses a set of hierarchical diagrams. Those diagrams are system context, containers, components, and code. Each of those two lists ends with code. Supporting diagrams are the system landscape, dynamic diagrams, and deployment diagrams. The approach is notation independent. It is also tooling independent. A talk titled Visualising software architecture with the C4 model was recorded at Agile on the Beach 2019 in July 2019. The page shows a book titled The C4 model by Simon Brown. The home page lists five numbered ideas. This note also lists structurizr and arc42 next to the C4 model link.
