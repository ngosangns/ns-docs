# Overview

A compilation of material on system design, software architecture, design patterns, and technical solutions. The notes move from fundamentals through architecture, detailed technical solutions, retry and circuit breaker, reference code, and attachments.

Fundamentals cover basic principles, trade-offs, and 8 common problems and solutions in system design. Software architecture covers Clean Architecture, Hexagonal, Microservices, EDA, DDD, CQRS, SOLID, AOP, Command Bus, and Event Loop. Detailed technical solutions cover JWT, caching, background jobs, notifications, e-commerce, TinyURL, rate limiting, migration, and web crawling.
