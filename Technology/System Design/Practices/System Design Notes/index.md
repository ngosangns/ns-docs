# Concepts

- [Attachments](Technology/System%20Design/Practices/System%20Design%20Notes/Attachments.md) - An index of PDF references and diagrams attached to the system design notes, from TinyURL designs to VietQR and Discord compression charts.
- [Edit History Backup](Technology/System%20Design/Practices/System%20Design%20Notes/Edit%20History%20Backup.md) - Community discussion on storing document edit history using versioned diffs with periodic full snapshots, plus comparisons to persistent segment trees, ropes, and git blobs.
- [Fundamentals](Technology/System%20Design/Practices/System%20Design%20Notes/Fundamentals.md) - An overview of system design fundamentals: the CAP consistency-availability trade-off, eight common problems with standard solutions, and a curated list of learning references.
- [Non Functional Requirements](Technology/System%20Design/Practices/System%20Design%20Notes/Non%20Functional%20Requirements.md) - Defines non-functional requirements and capabilities, and lists the steps to gather requirements before building an application.
- [Overview](Technology/System%20Design/Practices/System%20Design%20Notes/Overview.md) - A table of contents for the system design notes, covering fundamentals, software architecture, technical solutions, resilience patterns, and attachments.
- [Reference Code](Technology/System%20Design/Practices/System%20Design%20Notes/Reference%20Code.md) - A pointer to a sample backend blog application on GitHub for studying application architecture.
- [Retry And Circuit Breaker](Technology/System%20Design/Practices/System%20Design%20Notes/Retry%20And%20Circuit%20Breaker.md) - Covers retry with gradual backoff, the Circuit Breaker pattern, distributed transaction techniques such as SAGA, and the Outbox pattern for reliable messaging.
- [Software Architecture](Technology/System%20Design/Practices/System%20Design%20Notes/Software%20Architecture.md) - A survey of software architecture patterns (Clean, Hexagonal, Microservices, EDA, DDD, CQRS, LMAX, MVC family) and design principles (SOLID, DRY, AOP, Command Bus), with references and examples.
- [Technical Solutions](Technology/System%20Design/Practices/System%20Design%20Notes/Technical%20Solutions.md) - A curated catalog of detailed technical solutions and case studies, from JWT revocation, caching, and background jobs to TinyURL, ID generation, rate limiting, migrations, and scaling for traffic spikes.
