# Coding Interview Resources

**Updated 23/5/2022**

## Algorithms & Data Structures (DSA)

### Books

- **Introduction to Algorithms** (Thomas H. Cormen): Introductory, suitable for beginners
- **Grokking Algorithms** (Aditya Bhargava): Learn DSA with Python, suitable for beginners
- **Algorithms in a Nutshell** (George T. Heineman): Learn DSA with C++, Java, Python
- **Introduction to Algorithms: A Creative Approach** (Udi Manber): Advanced
- **Data Structures and Algorithms** (Cấu trúc dữ liệu và giải thuật; Hanoi University of Science and Technology - Assoc. Prof. Dr. Nguyễn Đức Nghĩa): Suitable for beginners

### Online Courses

- **Algorithm Specialization - Stanford University** (Coursera): 4 courses, rated 4.8/5, certificate available
- **Micro Master Program - UC San Diego**: MicroMasters program, earns credits
- **FSE k03**: The Future Software Engineer course on DSA and coding interviews

### Practice Websites

- **Leetcode.com**:
  - The leading website for practicing algorithms
  - See optimal solutions
  - Solution ranking system
  - Leetcode Premium: Problem types that frequently appear in coding interviews
- **Hackerrank.com**:
  - Similar to Leetcode
  - Almost all features are free
  - Some companies send questions through Hackerrank (Expedia, GE, Goldman Sachs)

## Coding Interviews

### Books

- **Cracking the Coding Interview** (Gayle Laakmann McDowell): The essential book
- **Programming Interviews Exposed** (John Mongan): An introduction to programming interviews

### Mock Interview Websites

- **Interview.io**: Practice interviews and coding interviews, rates around $200/h
- **Hackpack.xyz**: Matching and practicing mock interviews
- **FSE Mock Interview Discord server**: Practice mock interviews together

### Online Courses

- **Grokking the Coding Interview**: 182 lectures, 125 challenges, $10/month subscription
- **FSE k03**: Hands-on DSA & coding interview course, 4 instructors working at Big Tech

- **FB group Viet Tech**: Coding interview experiences at FAANG and Big Tech
