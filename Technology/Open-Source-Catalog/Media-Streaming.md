# Media Streaming

## Stremio

- **Repository**: https://github.com/Stremio/stremio-web
- **Description**: Phiên bản web của Stremio, một ứng dụng tổng hợp nội dung đa phương tiện
- **Features**:
  - Tổng hợp nội dung từ nhiều nguồn
  - Giao diện web hiện đại
  - Quản lý và xem phim, TV shows
  - Tích hợp add-ons để mở rộng chức năng
- **Use Cases**: Media streaming, content aggregation, entertainment platform
