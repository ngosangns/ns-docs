# Finance & Subscription Management

## Wallos

- **Repository**: https://github.com/ellite/Wallos
- **Description**: Ứng dụng web mã nguồn mở, tự host để quản lý subscription và chi phí định kỳ, giúp theo dõi và kiểm soát tài chính cá nhân
- **Features**:
  - Quản lý subscription và thanh toán định kỳ
  - Quản lý category tùy chỉnh
  - Hỗ trợ đa tiền tệ
  - Chuyển đổi tiền tệ với Fixer API
  - Bảo mật dữ liệu (self-hosted)
  - Tùy chỉnh categories, currencies, themes
  - Tìm kiếm logo tự động từ web
  - Mobile view
  - Thống kê chi tiêu
  - Notifications (email, discord, pushover, telegram, gotify, webhooks)
  - Đa ngôn ngữ
  - OIDC với OAuth
  - AI Recommendations (ChatGPT, Gemini, Ollama)
- **Tech Stack**: PHP 8.3, SQLite, Docker
- **License**: GPL-3.0
- **Demo**: https://demo.wallosapp.com (reset mỗi 2 giờ)
- **Use Cases**: Quản lý subscription cá nhân, theo dõi chi phí định kỳ, quản lý ngân sách
