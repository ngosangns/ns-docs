# Analytics

## Plausible Analytics

- **Repository**: https://github.com/plausible/analytics
- **Description**: Simple, open source, lightweight and privacy-friendly web analytics alternative to Google Analytics
- **Tech Stack**:
  - Elixir/Phoenix
  - PostgreSQL
  - ClickHouse
  - TailwindCSS
  - React
- **Features**:
  - Privacy-friendly (no cookies, GDPR compliant)
  - Lightweight (< 1KB script)
  - Self-hostable (Community Edition)
  - Managed cloud service available
  - EU-hosted infrastructure
  - No tracking, no ads
- **License**: AGPL-3.0 (Community Edition), MIT (JavaScript tracker)
- **Website**: https://plausible.io

## Umami

- **Repository**: https://github.com/umami-software/umami
- **Description**: Simple, fast, privacy-focused alternative to Google Analytics
- **Features**:
  - Privacy-focused (no cookies, GDPR compliant)
  - Lightweight and fast
  - Self-hostable
  - Simple and clean interface
  - Real-time analytics
  - Multiple websites support
- **Tech Stack**: Next.js, MySQL/PostgreSQL
- **License**: MIT

## PostHog

- **Repository**: https://github.com/PostHog/posthog
- **Description**: Open-source product analytics platform, alternative to Amplitude, Mixpanel, and Heap
- **Features**:
  - Product analytics
  - Feature flags
  - Session recordings
  - A/B testing
  - User surveys
  - Self-hostable
  - Cloud service available
- **Tech Stack**: Python, React, PostgreSQL, ClickHouse
- **License**: MIT
- **Website**: https://posthog.com

## Vemetric

- **Repository**: https://github.com/vemetric/vemetric
- **Description**: Công cụ phân tích web và sản phẩm đơn giản nhưng mạnh mẽ
- **Features**:
  - Web analytics
  - Product analytics
  - Simple and powerful
