# Java Spring

This note collects Spring Boot resources. The main series is Nhật ký Spring Boot by Vu Tong on Viblo, published on 22 January 2021. He wrote it after a full six months on a Java Spring Boot project, as notes to review and to share. The series starts with where to begin and how to create a first project.

Later posts cover the request flow, dependency injection, beans and ApplicationContext, bean lifecycle, bean types, and component scan. He also mentions Javatpoint, Logicbig, and the Spring Boot homepage, plus a Vietnamese zero to hero series.
