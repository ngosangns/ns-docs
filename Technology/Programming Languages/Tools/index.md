- [Laravel Validation Rule Builders](Technology/Programming%20Languages/Tools/Laravel%20Validation%20Rule%20Builders.md) - Laravel 13.36 (framework PR 61833, released 2026-10-13) adds a Rule:: builder for every validation rule that was still string-only (Rule::requiredWithout, Rule::url()->protocols, Rule::uuid()->version, Rule::distinct()->ignoreCase, and others), plus Rule::date()->equals. Builders give IDE autocompletion and pass parameters as arrays, so values containing commas, quotes or pipes no longer break; string rules still work and can be mixed in.
- [Nodejs](Technology/Programming%20Languages/Tools/Nodejs.md) - Curated list of Node.js web frameworks, ORMs, libraries, an experimental low-latency runtime, and a request validator.
- [Rul](Technology/Programming%20Languages/Tools/Rul.md) - Rul (rul-lang/rul, .rl) is a dependency-free Rust engine in which an AI agent emits a 128-bit-per-node SSA dataflow graph of f64 columnar ops, a single forward pass verifies it, three execution tiers run it, and a 991-line emitter writes a standalone Linux x86-64 ELF with no LLVM or libc. The 192 B program and 817 B ELF are real; the 5.78 ns/node and 6.38 µs headline figures did not reproduce (19.4 ns/node, 19.7 µs on Apple silicon), and the 'language' has 15 opcodes, no control flow, and a stub I/O op.
- [Tsc Ts](Technology/Programming%20Languages/Tools/Tsc%20Ts.md) - tsc-ts (vercel-labs/tsc-ts, npm tsc-ts 0.0.5, Apache-2.0) is a Vercel Labs experiment that ports the TypeScript 7.0.2 compiler (typescript-go / tsgo) back into TypeScript and compiles it to a native executable with scriptc. It takes the same arguments as tsc, adds a stdin/stdout --api server and a tsc-ts/api programmatic API, and claims its scanner, parser, binder, checker, emit, and build modes match tsgo on TypeScript's test corpus.
