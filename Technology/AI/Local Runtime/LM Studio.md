# Tổng quan

LM Studio là ứng dụng desktop giúp tải, chạy và tương tác với các mô hình LLM ngay trên máy tính. Hỗ trợ server API tương thích OpenAI để tích hợp dễ dàng vào dự án, phù hợp cho thử nghiệm, chat và triển khai nội bộ.
