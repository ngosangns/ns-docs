# Local Runtime

- **LM Studio**: Ứng dụng desktop giúp tải, chạy và tương tác với các mô hình LLM ngay trên máy tính. Hỗ trợ server API tương thích OpenAI để tích hợp dễ dàng vào dự án, phù hợp cho thử nghiệm, chat và triển khai nội bộ.
  - Model catalog: https://lmstudio.ai/models
  - SDK: [TypeScript](https://github.com/lmstudio-ai/lmstudio-js) | [Python](https://github.com/lmstudio-ai/lmstudio-python) #local-runtime #LLM #desktop
- **Ollama**: Runtime LLM cục bộ với CLI đơn giản, hỗ trợ tải/chạy nhiều model (Llama, Qwen, Mistral…). Cung cấp server tương thích OpenAI để tích hợp nhanh vào ứng dụng, phù hợp cho thử nghiệm offline và prototyping. Model catalog: https://ollama.com/search #local-runtime #LLM #CLI
- **IchigoLLaMA3.1**: Mô hình AI giọng nói thời gian thực chạy cục bộ, mã nguồn mở. Hoạt động trên GPU NVIDIA 3090, không cần kết nối internet, đảm bảo quyền riêng tư và giảm độ trễ. Tính năng: nhận dạng và tổng hợp giọng nói thời gian thực, phản hồi khi không hiểu đầu vào. Ứng dụng: trợ lý ảo, tổng hợp giọng nói, các ứng dụng giọng nói yêu cầu quyền riêng tư cao #local-runtime #voice #TTS #real-time #privacy
