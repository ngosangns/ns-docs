  - **getimg.ai**: Nền tảng AI đa năng cho việc tạo và chỉnh sửa hình ảnh, video
    - Tạo hình ảnh/video từ mô tả văn bản trong vòng chưa đầy 60 giây, không cần kiến thức về prompt engineering
    - Hỗ trợ hơn 20 ngôn ngữ
    - Truy cập hơn 25 mô hình AI hàng đầu (FLUX, Sora, Kling, GPT Image, Gemini) với một gói đăng ký duy nhất
    - Tính năng chỉnh sửa: Thêm đối tượng, khôi phục ảnh cũ, thay đổi nền, tăng độ phân giải
    - Tạo nội dung nhất quán bằng cách sử dụng hình ảnh tham chiếu
    - Hỗ trợ làm việc nhóm với không gian làm việc chung
    - Nguồn: https://getimg.ai/ #text2image #image-editing #AI-platform
  - **FLUX.1 Kontext**: Bộ mô hình generative flow matching cho phép tạo và chỉnh sửa hình ảnh với in-context generation. Hỗ trợ character consistency, local editing, style reference và iterative editing. Tốc độ inference nhanh hơn 8x so với các mô hình hàng đầu. Các mô hình: FLUX.1 Kontext [pro] (tiên phong cho chỉnh sửa nhanh, lặp lại), [max] (cải thiện prompt adherence, typography), [dev] (open-weight 12B). Đánh giá trên KontextBench đạt top performers. Website: https://playground.bfl.ai #text2image #image-editing #in-context #FLUX
  - **Meshy.ai**: Công cụ AI tạo mô hình 3D từ văn bản hoặc hình ảnh trong vài giây
    - Tính năng: Image to 3D, Text to 3D (đa ngôn ngữ), AI Texturing (PBR maps cho Unreal, Unity, Blender, Maya, WebGL), Animation (tự động rigging), 3D to Video, Smart Remesh, Text to Image
    - Production Ready: Asset management, private licensed, multiple 3D file formats (FBX, GLB, OBJ, STL, 3MF, USDZ, BLEND), resize và pivot tool, multiple concurrent tasks (50+)
    - Workflow Integration: REST API, plugins cho Blender, Unity, 3ds Max, Maya, Godot, Unreal Engine, Bambu Studio
    - Enterprise Features: Multi-team management, shared workspace, ISO27001/SOC2 Type II/GDPR certifications, SSO, increased data privacy, dedicated support, forever asset retention
    - Use Cases: Film Production (VFX, previsualization), Product Design, Education, Game Development, 3D Printing, VR/AR, Interior Design, E-commerce, Toy Design
    - Lợi ích: 10x nhanh hơn phương pháp truyền thống, giảm chi phí lên đến 100x, không cần kỹ năng modeling chuyên biệt
    - Website: https://www.meshy.ai/ #3D-generation #text-to-3D #image-to-3D #AI-modeling
