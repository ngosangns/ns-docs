# Tổng quan

Ollama là runtime LLM cục bộ với CLI đơn giản, hỗ trợ tải/chạy nhiều model (Llama, Qwen, Mistral…). Cung cấp server tương thích OpenAI để tích hợp nhanh vào ứng dụng, phù hợp cho thử nghiệm offline và prototyping.
