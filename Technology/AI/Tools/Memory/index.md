# Concepts

- [Claude Code Memory Analysis](Technology/AI/Tools/Memory/Claude%20Code%20Memory%20Analysis.md) - An evaluation of Claude Code's built-in memory system (CLAUDE.md and auto memory) versus the Claude-Mem plugin, with guidance on when the plugin is worth adding.
- [Claude Mem](Technology/AI/Tools/Memory/Claude%20Mem.md) - Claude-Mem is a persistent memory compression system for Claude Code that captures sessions, compresses them with AI, and injects relevant context into future sessions.
- [Code Review Graph](Technology/AI/Tools/Memory/Code%20Review%20Graph.md) - Code Review Graph is a local Tree-sitter knowledge graph for AI coding tools that cuts tokens on code reviews and provides blast-radius impact analysis, with a full install, CLI, and troubleshooting guide.
- [Codebase Memory MCP](Technology/AI/Tools/Memory/Codebase%20Memory%20MCP.md) - codebase-memory-mcp (DeusData/CBM) is a zero-dependency, pure C code intelligence MCP server that indexes 162 languages into a queryable knowledge graph.
- [CodeGraph](Technology/AI/Tools/Memory/CodeGraph.md) - CodeGraph is an MIT-licensed code knowledge graph with a native Rust kernel, auto-sync, and surgical context retrieval for coding agents.
- [GitNexus](Technology/AI/Tools/Memory/GitNexus.md) - GitNexus is a zero-server code intelligence engine that indexes codebases into knowledge graphs and exposes them to AI agents through a CLI, MCP tools, and a browser-based Web UI.
- [Graph Comparison](Technology/AI/Tools/Memory/Graph%20Comparison.md) - A comparison of five memory and knowledge-graph tools (semantica, trustgraph, mempalace, neural-memory, knowns) that combine graph storage with semantic/vector search, with a quick decision table.
- [Graphify](Technology/AI/Tools/Memory/Graphify.md) - Graphify is a Claude Code skill that turns codebases, docs, papers, images, and videos into queryable knowledge graphs, cutting token usage substantially compared with reading raw files.
- [Knowns](Technology/AI/Tools/Memory/Knowns.md) - Knowns is a local-first, self-hostable memory layer for AI-native development that gives AI assistants persistent project context across tasks, docs, memories, and code intelligence.
- [Mem0](Technology/AI/Tools/Memory/Mem0.md) - Mem0 is a popular universal memory layer for AI agents and assistants offering multi-level user, session, and agent memory with Python and Node.js SDKs and an optional managed service.
- [Memory Tool Comparison](Technology/AI/Tools/Memory/Memory%20Tool%20Comparison.md) - A feature-by-feature comparison of 15 AI memory, knowledge graph, RAG, and development workflow tools covering storage, memory types, integrations, tech stack, benchmarks, and when each one is worth adopting.
- [MemPalace](Technology/AI/Tools/Memory/MemPalace.md) - MemPalace is a free, local-only AI memory system that stores raw verbatim exchanges in ChromaDB with a SQLite knowledge graph and reports the highest LongMemEval score at 96.6% R@5.
- [MemU](Technology/AI/Tools/Memory/MemU.md) - MemU is a hierarchical memory framework for 24/7 proactive AI agents that cuts LLM token costs and infers user intent without explicit commands, available self-hosted or as a cloud API.
- [Neural Memory](Technology/AI/Tools/Memory/Neural%20Memory.md) - An open-source Python library that gives AI agents persistent, graph-based memory recalled through spreading activation, with MCP tools, a CLI, and offline-first storage.
- [Other Memory Tools](Technology/AI/Tools/Memory/Other%20Memory%20Tools.md) - A curated list of additional memory and knowledge-graph tools for AI coding agents that do not have their own notes.
- [RAGFlow](Technology/AI/Tools/Memory/RAGFlow.md) - An open-source Retrieval-Augmented Generation engine that combines deep document understanding, template-based chunking, grounded citations, and agent capabilities.
- [Repowise](Technology/AI/Tools/Memory/Repowise.md) - A codebase intelligence tool that merges a code graph, git history, docs, architectural decisions, and code health into one index for both agents and humans.
- [Semantica](Technology/AI/Tools/Memory/Semantica.md) - An open-source framework for building context graphs and decision-intelligence layers with reasoning engines, temporal queries, provenance tracking, and ontology support.
- [Source Code Indexing Comparison](Technology/AI/Tools/Memory/Source%20Code%20Indexing%20Comparison.md) - An evaluation of memory and graph tools for indexing and searching source code, with recommendations by use case and a decision tree.
- [Superpowers](Technology/AI/Tools/Memory/Superpowers.md) - An agentic skills framework and software development methodology that gives coding agents a complete brainstorm-to-merge workflow built on composable skills.
- [Think Better](Technology/AI/Tools/Memory/Think%20Better.md) - A CLI that injects structured decision and problem-solving frameworks, with cognitive-bias warnings, into AI prompts for Claude Code, Copilot, and Antigravity.
- [TrustGraph](Technology/AI/Tools/Memory/TrustGraph.md) - A self-hosted context development platform that stores, enriches, and retrieves structured knowledge through a multi-model database, graph-native RAG pipelines, and portable context cores.
- [Zvec](Technology/AI/Tools/Memory/Zvec.md) - Alibaba's open-source in-process vector database, built on Proxima, offering fast dense and sparse vector search with hybrid filtering and no server to run.
