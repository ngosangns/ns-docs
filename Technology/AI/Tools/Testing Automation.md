# Testing Automation

This note points at browserbase/stagehand. The GitHub README calls Stagehand the SDK for browser agents. It says the project is the SDK to extract data and interact with sites on the web. The same page ships TypeScript, Python, and Go, and it is MIT licensed, copyright 2026 Browserbase, Inc.

The README names three calls. `observe` finds elements. `act` performs a step and can refresh that step when a site changes. `extract` returns schema-checked data. Local runs use Chrome. The same script can target Browserbase instead of a local browser. Docs live at docs.stagehand.dev. The README also lists Playwright-style methods such as goto, click, locator, and screenshot. It says a local run needs Chrome installed. Install lines on that page use pnpm, pip, and go get. The README says Stagehand is a trademark of Browserbase, Inc.
