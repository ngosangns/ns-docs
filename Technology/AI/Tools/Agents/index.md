- [Cloudflare Web Search API](Technology/AI/Tools/Agents/Cloudflare%20Web%20Search%20API.md) - Cloudflare's open-beta Web Search API sends a query through AI Gateway to Ceramic.ai, Exa, or Linkup and returns one result shape, billed at each provider's list price.
- [Coding Agents](Technology/AI/Tools/Agents/Coding%20Agents.md) - Curated overview of AI coding agents, CLIs, VS Code extensions, IDEs, and app builders such as OpenCode, Devin, Cosine, Dyad, and Kilo.
- [Eve](Technology/AI/Tools/Agents/Eve.md) - eve (vercel/eve, npm eve 0.80.1, Apache-2.0, public beta) is Vercel's filesystem-first TypeScript framework for durable backend AI agents - an agent is an agent/ directory of instructions, tools, skills, connections, channels, schedules and subagents; sessions run as Workflow SDK durable workflows with a per-session sandbox, evals, useEveAgent frontend hooks, and Agent Runs tracing on Vercel or self-hosted on Node.
- [Google AX](Technology/AI/Tools/Agents/Google%20AX.md) - Google's pre-stable agent orchestration runtime. kubectl-style Task, Workspace, and Model manifests, sandboxed as actors on Agent Substrate, with checkpoint suspend and resume.
- [gstack](Technology/AI/Tools/Agents/Gstack.md) - gstack (garrytan/gstack, MIT) is Garry Tan's skill pack that adds review, QA, and release commands to coding agents. Checked 3 November 2026, main VERSION is 1.93.21.0, the newest GitHub release is v1.92.55.0, and the pack was not installed.
- [Kanzo](Technology/AI/Tools/Agents/Kanzo.md) - Kanzo (emanuele-em/kanzo, AGPL-3.0, v0.3.0) is a self-hosted kanban board and MCP server in one Rust binary, so a person and coding agents share the same local tasks.
- [ktx](Technology/AI/Tools/Agents/Ktx.md) - ktx (npm @kaelio/ktx 0.16.0, Kaelio/ktx, Apache-2.0) is a local context layer that turns a SQL warehouse and team docs into a wiki and semantic layer, then serves approved metrics to coding agents over a CLI and MCP; the unscoped npm package ktx and the Khronos KTX texture format are different projects.
- [Multi Agent Systems](Technology/AI/Tools/Agents/Multi%20Agent%20Systems.md) - Curated list of frameworks and platforms for building multi-agent systems, including Agno, TinyTroupe, Google ADK, Dify, and TradingAgents.
- [Nuphos](Technology/AI/Tools/Agents/Nuphos.md) - Nuphos (nuphos/nuphos, Apache-2.0, by Zeabur Inc.) is a team workspace for coding agents - Claude Code, Codex, Grok Build, Antigravity and OpenCode run over ACP on local, remote or cloud runtimes, with shared multi-user sessions, team skills, memory and credentials, DevOps GUIs (Kubernetes, Grafana, cloud consoles), Slack/Discord, triggers, and Electron/iOS/CLI clients. Early access; the Desktop app ships PostHog analytics with session replay on by default.
- [OpenCodeReview](Technology/AI/Tools/Agents/OpenCodeReview.md) - Alibaba's open-source AI code review CLI (ocr) using a hybrid deterministic-pipeline + LLM-agent architecture for precise line-level comments, with delegation mode for host agents and CI/CD integrations.
- [OpenDuet](Technology/AI/Tools/Agents/OpenDuet.md) - OpenDuet (CopilotKit/OpenDuet, MIT) is an early self-hosted template for a proactive agent, built on a vendored OpenBot tree, with mail triage and a morning brief, and the server refuses to start without a CopilotKit Intelligence key.
- [OpenMausBot](Technology/AI/Tools/Agents/OpenMausBot.md) - OpenMausBot (milind-soni/OpenMausBot, Apache-2.0) is a local-first chat app that runs a team of coding-agent bots. Checked 3 November 2026, main is package 0.1.139, the newest GitHub release and npm latest are 0.1.138, and the app was not installed.
- [OpenWorker](Technology/AI/Tools/Agents/OpenWorker.md) - OpenWorker (andrewyng/openworker, MIT) is a local desktop AI coworker with a Python server and a Tauri shell. Checked 3 November 2026, the Tauri config and Python package on main say 0.3.4, the newest GitHub release is v0.3.1, and PyPI openworker is 0.0.1.
- [Pi Durable](Technology/AI/Tools/Agents/Pi%20Durable.md) - Experimental durable agent harness from Earendil (shipped with Pi 1.0) for long-running, crash-survivable, multi-conversation agent apps over memory/JSONL/SQLite storage, with pluggable extensions, tools, hooks, tasks, compaction, and documents.
- [Pstack](Technology/AI/Tools/Agents/Pstack.md) - pstack (cursor/plugins, MIT, v0.15.36) is Lauren Tan's Cursor plugin of markdown skills. poteto-mode matches one of 23 playbooks and the model follows that file. There is no router process.
- [REA](Technology/AI/Tools/Agents/REA.md) - REA (npm rea-agents 6.8.0, MIT) is a local CLI and MCP server that returns evidence for native binaries, JavaScript, Electron, .NET, Android, firmware, browsers, and other static formats. Checked 2 November 2026: GitHub lists 420,599 stars, the site is rea.tools, and main has commits after the 25 October 2026 npm release.
- [Skill Recorder](Technology/AI/Tools/Agents/Skill%20Recorder.md) - Skill Recorder (microsoft/skill-recorder, MIT, Electron + TypeScript) records a screen session on-device, optionally transcribes narration with Whisper and blurs OCR-located text before anything leaves the machine, has GitHub Copilot reconstruct the intent and ordered steps, then renders a SKILL.md into ~/.copilot/skills or a Scout automation. 5.4k stars, v0.7.0.
- [Treg](Technology/AI/Tools/Agents/Treg.md) - treg is an open-source tool catalog and credential-injecting proxy for AI agents — one token for 4,000+ priced API endpoints across 121 providers, plus a team's own keys, CLIs and skills, with $1 free credit and 0% markup.
- [Unreal Agent](Technology/AI/Tools/Agents/Unreal%20Agent.md) - Open-source AI editor copilot plugin for Unreal Engine 5.6 that runs as a dockable in-editor chat tab, drives the editor via Python execution, scene queries, viewport screenshots, and optional MCP/Replicate tools.
- [Zeron](Technology/AI/Tools/Agents/Zeron.md) - Native local-first control plane (Rust, gpui) for driving coding agents such as Claude Code, Codex, Cursor, Devin, Grok, Hermes, Pi, and Antigravity, with optional multi-device sync over Loro and Cloudflare Durable Objects.
