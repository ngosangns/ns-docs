# Other Kits

Other Kits is where related Claude Code tooling sits until it has its own note. The note starts with blink-query. That project is the GitHub repo arpitnath/blink-query. GitHub hosts the repo. The bullet calls it a companion query utility. Claude Capsule Kit is the kit that uses it. The kit stores and queries blink-query namespaces. Those namespaces are session memory storage. A store writes memory into a namespace. A query reads memory from a namespace. You can also use blink-query standalone. Standalone search looks through structured project context. Standalone retrieve brings that context back. The closing links point to Claude Capsule Kit, which uses the utility, and to Kit Comparison.

- [arpitnath/blink-query](https://github.com/arpitnath/blink-query) — Companion query utility used by [Claude Capsule Kit](/Technology/AI/Tools/Agents/Claude Code Kits/Claude Capsule Kit) to store and query "blink-query namespaces" (session memory storage). It can also be used standalone to search and retrieve structured project context.
