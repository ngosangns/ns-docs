# Concepts

- [Brave AI](Technology/AI/Tools/Data/Brave%20AI.md) - Brave's AI page covers Ask Brave, the Leo browser assistant, and the Brave Search API. The API serves its own index at $5 per 1,000 search requests, with $5 of free credit a month.
- [Data Tools](Technology/AI/Tools/Data/Data%20Tools.md) - Curated tools for analytics and tabular ML, document processing, and knowledge or data management.
- [Exa](Technology/AI/Tools/Data/Exa.md) - Exa is a paid web index and retrieval API for agents. Search starts at $4 per 1,000 requests, contents at $1 per 1,000 pages, and a new account gets $10 in credits each month.
- [Nemotron Parse 2.0](Technology/AI/Tools/Data/Nemotron%20Parse%202.0.md) - NVIDIA Nemotron Parse 2.0 is an OpenMDW-1.1 vision-encoder-decoder under 1 billion parameters that turns a document image and a task prompt into text, layout classes, and bounding boxes. The Hub card names nvidia/Nemotron-3.5-Parse as the newer model.
- [SearXNG](Technology/AI/Tools/Data/SearXNG.md) - SearXNG is an AGPL-3.0 metasearch engine you host yourself. It queries other engines, including Brave, Exa, Google, and Bing, and it does not keep a user profile.
