# Concepts

- [Comic Translate](Technology/AI/Tools/Manga%20Translator/Comic%20Translate.md) - Comic-Translate is a desktop app that translates manga, manhwa, BDs and other comics from images, PDF, Epub, CBR and CBZ using detection, OCR, LLM translation and inpainting.
- [Cotrans](Technology/AI/Tools/Manga%20Translator/Cotrans.md) - Cotrans is a collaborative online manga translation platform built on manga-image-translator, offering a web UI, browser extension and worker-based backend.
- [Koharu](Technology/AI/Tools/Manga%20Translator/Koharu.md) - Koharu is a local-first, ML-powered manga translator written in Rust with a Tauri desktop app, combining detection, OCR, inpainting and local or cloud LLMs.
- [Manga Image Translator](Technology/AI/Tools/Manga%20Translator/Manga%20Image%20Translator.md) - Manga-Image-Translator is the flagship open-source modular manga translation pipeline with pluggable detectors, OCR engines, inpainters and translators, usable via Web UI, CLI, API and WebSocket.
- [Manga Translator Others](Technology/AI/Tools/Manga%20Translator/Manga%20Translator%20Others.md) - A curated list of additional manga translator projects beyond the main tools, grouped into desktop/web apps, Android apps, libraries, commercial services and discussions.
- [Tachiyomi AT](Technology/AI/Tools/Manga%20Translator/Tachiyomi%20AT.md) - TachiyomiAT is a Mihon (Tachiyomi) fork for Android that adds automatic manga translation using ML Kit, Google Translate, Gemini or OpenRouter.
- [Translator Comparison](Technology/AI/Tools/Manga%20Translator/Translator%20Comparison.md) - Side-by-side comparison of open-source and commercial manga/comic translator tools by stars, license, platform, OCR, inpainting and translation method, with top picks per need.
