- [campfirein/cipher](https://github.com/campfirein/cipher) — Byterover Cipher, memory layer mã nguồn mở dành riêng cho coding agent, tương thích Cursor, Windsurf, Claude Code, Cline, Claude Desktop, Gemini CLI, AWS Kiro, VS Code, Roo Code, Trae, Amp Code, Warp qua MCP.
- [steveyegge/beads](https://github.com/steveyegge/beads) — Beads, nâng cấp bộ nhớ cho agent lập trình.
- Vertex AI Agent Engine Memory Bank — dịch vụ memory quản lý của Google Cloud cho AI agent.
- Supermemory.ai — nền tảng Memory API xây dựng lớp ghi nhớ bền vững ("bộ não số" thứ hai): semantic/AI search, hỗ trợ đa dạng content (text, URL, PDF, ảnh, video), tích hợp Notion/Google Drive/CRM/Zapier/Chrome extension, canvas UI + writing assistant, hỗ trợ cloud/on-premises/on-device.
- [TencentCloud/TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory) — hệ thống long-term memory chạy hoàn toàn local của Tencent; pipeline 4 tầng tiến triển (L0→L3 Persona) kết hợp FTS5 + EmbeddingGemma hybrid recall, không phụ thuộc API bên ngoài.
- [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything) — biến bất kỳ codebase/knowledge base/docs nào thành interactive knowledge graph; pipeline multi-agent Tree-sitter + LLM với dashboard trực quan, hoạt động trên Claude Code, Codex, Cursor, Copilot, Kiro và nhiều agent khác.
