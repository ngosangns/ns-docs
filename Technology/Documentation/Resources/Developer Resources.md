# Developer Resources

- **tool**
  - [HTTPie for Web là client test API dựa trên trình duyệt cung cấp giao diện sạch, trực quan để gửi HTTP request và kiểm tra response. Được xây dựng như phiên bản web của công cụ dòng lệnh HTTPie phổ biến, hỗ trợ tất cả phương thức HTTP, header tùy chỉnh, xác thực, request body và query parameter. Người dùng có thể tổ chức request thành bộ sưu tập, lưu và chia sẻ, xem response được định dạng với tô sáng cú pháp. Ứng dụng được thiết kế để test và debug API dễ dàng, thay thế hiện đại cho Postman với tập trung vào sự đơn giản.](https://httpie.io/app)
  - [Typst là hệ thống sắp chữ markup hiện đại và ứng dụng web cộng tác, thay thế cho LaTeX và Word. Cho phép viết tài liệu bằng ngôn ngữ markup sạch, trực quan với xem trước thời gian thực và biên dịch tức thì. Hỗ trợ toán học, thư mục, hình ảnh, bảng, tô sáng mã và bài thuyết trình ngay trong hộp, với ngôn ngữ script nhúng mạnh mẽ cho tự động hóa. Nền tảng có tính năng cộng tác nhóm, package riêng tư, tích hợp Git, template và đồng bộ Zotero. Với hơn 1200 package và template cộng đồng, Typst được sử dụng cho bài báo, luận văn và báo cáo.](https://typst.app/)
  - [aaencode là công cụ trực tuyến chuyển đổi chương trình JavaScript thành mã chỉ sử dụng kaomoji phong cách Nhật Bản. Người dùng nhập JavaScript tiêu chuẩn, công cụ mã hóa thành mã chỉ gồm các biểu tượng cảm xúc như ^\_^ vẫn có thể thực thi. Đầu ra mã hóa có thể chạy bằng eval JavaScript, tạo cùng kết quả với mã gốc. Công cụ chủ yếu được tạo để giải trí và trình diễn kỹ thuật mã hóa JavaScript, thể hiện sự linh hoạt của mã hóa ký tự ngôn ngữ.](https://utf-8.jp/public/aaencode.html)
  - [Obfuscator.io là công cụ obfuscation JavaScript trực tuyến mạnh mẽ giúp bảo vệ mã nguồn JavaScript khỏi kỹ thuật đảo ngược và đánh cắp. Biến đổi code dễ đọc thành mã khó hiểu thông qua kỹ thuật mã hóa chuỗi, làm phẳng luồng điều khiển, chèn dead code và cơ chế tự bảo vệ. Nền tảng cũng cung cấp obfuscation VM nâng cao chuyển JavaScript thành bytecode tùy chỉnh chạy trên máy ảo nhúng, khiến deobfuscation cực kỳ khó khăn. Hỗ trợ nhiều preset cấu hình, tối ưu Node.js và cung cấp cả playground miễn phí lẫn gói VM bảo vệ trả phí.](https://obfuscator.io/)
  - [JSON Editor Online là công cụ đa năng dựa trên web để xem, chỉnh sửa, định dạng và xử lý dữ liệu JSON. Cung cấp nhiều chế độ chỉnh sửa bao gồm text, tree và table, giúp dễ dàng điều hướng và sửa đổi cấu trúc JSON phức tạp. Tính năng chính bao gồm định dạng JSON, xác thực schema, so sánh tài liệu, sửa JSON, truy vấn và biến đổi dữ liệu, chuyển đổi CSV. Trình chỉnh sửa hỗ trợ file lớn đến 512MB, hoạt động ngoại tuyến và cho phép lưu chia sẻ tài liệu, là công cụ thiết yếu cho lập trình viên frontend và backend.](https://jsoneditoronline.org/)
  - [Cron-job.org là dịch vụ lập lịch cron job trực tuyến miễn phí cho phép thực thi URL website và script theo khoảng thời gian cấu hình từ mỗi phút đến mỗi năm.   - [erd-editor là trình chỉnh sửa Entity-Relationship Diagram mã nguồn mở có sẵn dưới dạng ứng dụng web, tiện ích VSCode và plugin IntelliJ. Công cụ cho phép nhà phát triển thiết kế schema cơ sở dữ liệu trực quan, xác định bảng, cột, mối quan hệ và tạo câu lệnh SQL.   - [DrawDB là trình chỉnh sửa sơ đồ cơ sở dữ liệu trực tuyến miễn phí và trình tạo SQL cho phép thiết kế schema cơ sở dữ liệu trực quan qua giao diện kéo thả trực quan. Người dùng có thể tạo bảng, xác định cột với kiểu dữ liệu, thiết lập khóa chính và khóa ngoại, thiết lập mối quan hệ giữa các bảng, sau đó tự động tạo script SQL cho nhiều hệ cơ sở dữ liệu.
