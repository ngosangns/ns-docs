# Testing Tools

## MQTT Clients

- **MQTT.fx**: Desktop client để test MQTT messaging
- **MQTT Explorer**: Tool để explore và test MQTT topics

## Debugging Tools

- **Serial monitors**: Để debug firmware trên microcontrollers
- **Network analyzers**: Wireshark để analyze network traffic
