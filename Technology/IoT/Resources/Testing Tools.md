# Testing Tools

This page is a curated list of MQTT clients and debugging tools. The description limits that list to testing IoT messaging, firmware, and network traffic. The entries sit in two sections. MQTT Clients comes first. MQTT.fx is a desktop client for testing MQTT messaging. MQTT Explorer is a tool for exploring and testing MQTT topics. Those two are the only clients named. Debugging Tools comes second. Serial monitors are for debugging firmware on microcontrollers. Network analyzers are listed with them. Wireshark is the only analyzer named, and the note gives it the job of analyzing network traffic. Each line is only a tool name and a role. See also names Messaging Protocols and Simulation Tools. The page tags are technology, iot, and testing.

## MQTT Clients

- **MQTT.fx**: Desktop client for testing MQTT messaging
- **MQTT Explorer**: Tool for exploring and testing MQTT topics

## Debugging Tools

- **Serial monitors**: For debugging firmware on microcontrollers
- **Network analyzers**: Wireshark for analyzing network traffic
