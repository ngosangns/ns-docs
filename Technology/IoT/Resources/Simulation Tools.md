# Simulation Tools

This list collects visual programming tools and cloud simulators for prototyping and simulating IoT devices and flows. Under visual programming, Node-RED is visual programming for IoT flows, and Cayenne is a drag-and-drop IoT builder. Under cloud simulators, AWS IoT Device Simulator is for simulating devices on AWS. Related notes are Testing Tools and Development Tools.

The Node-RED homepage calls it low-code programming for event-driven applications. It says the goal is to collect, transform, and visualize data by building flows. It is built on Node.js. The same page lists the latest npm release as v5.0.9. Cayenne stays a one-line drag-and-drop builder in this note. AWS IoT Device Simulator stays a one-line simulator for devices on AWS. This page does not add setup steps for either of those two.

## Visual Programming

- **Node-RED**: Visual programming for IoT flows
- **Cayenne**: Drag-and-drop IoT builder

## Cloud Simulators

- **AWS IoT Device Simulator**: Simulate devices on AWS
