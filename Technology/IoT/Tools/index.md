# Concepts

- [Development Tools](Technology/IoT/Tools/Development%20Tools.md) - Curated list of firmware development tools and edge AI projects for building IoT devices.
- [Gokino](Technology/IoT/Tools/Gokino.md) - Gokino (gokino.dev) is a browser Arduino IDE that compiles sketches in the cloud, flashes boards over WebSerial, and meters an AI assistant with credits.
- [Learn Arduino](Technology/IoT/Tools/Learn%20Arduino.md) - Learn Arduino (learn-arduino-red.vercel.app) is a free interactive 3D Arduino Uno course by Dilum Sanjaya — 16 pre-wired lessons with adjustable parameters, simulated sketches, serial output and a generated schematic view, in 13 languages with no setup or account.
