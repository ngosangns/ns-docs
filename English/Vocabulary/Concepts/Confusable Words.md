# Confusable Words

Pairs that look, sound, or translate alike but differ in meaning or use — a favourite source of exam distractors.

## Same Root, Different Meaning

| Pair                         | Difference                                      | Example                                             |
| ---------------------------- | ----------------------------------------------- | --------------------------------------------------- |
| economic / economical        | of the economy / saving money                   | _economic growth_ vs _an economical car_            |
| historic / historical        | important in history / related to history       | _a historic victory_ vs _historical records_        |
| sensible / sensitive         | reasonable / easily hurt, aware                 | _a sensible decision_ vs _sensitive skin_           |
| continual / continuous       | repeated with breaks / without breaks           | _continual interruptions_ vs _continuous noise_     |
| uninterested / disinterested | bored / impartial                               | _uninterested in sports_ vs _a disinterested judge_ |
| electric / electrical        | powered by electricity / related to electricity | _an electric guitar_ vs _electrical engineering_    |
| childish / childlike         | immature (negative) / innocent (positive)       | _childish behaviour_ vs _childlike wonder_          |

## Different Function

| Pair                 | Difference                                        | Example                                                  |
| -------------------- | ------------------------------------------------- | -------------------------------------------------------- |
| affect / effect      | verb / noun                                       | _The news affected me._ · _The effect was big._          |
| rise / raise         | intransitive (rises on its own) / transitive      | _Prices rise._ · _Raise your hand._                      |
| lie / lay            | recline (lie-lay-lain) / put down (lay-laid-laid) | _Lie down._ · _Lay the book on the table._               |
| borrow / lend        | take from / give to                               | _Can I borrow your pen?_ · _Lend me your pen._           |
| imply / infer        | suggest (speaker) / deduce (listener)             | _He implied it._ · _I inferred it._                      |
| emigrate / immigrate | leave a country / enter a country                 | _emigrate from VN_ · _immigrate to Canada_               |
| bring / take         | toward speaker / away from speaker                | _Bring it here._ · _Take it there._                      |
| remember / remind    | recall yourself / make someone recall             | _I remember him._ · _You remind me of him._              |
| say / tell           | say sth / tell sb (sth)                           | _She said hello._ · _She told me a story._               |
| look / see / watch   | direct eyes / perceive / observe over time        | _Look at the sky._ · _I see a star._ · _Watch the film._ |
| win / earn / gain    | a game/prize / money for work / get gradually     | _win the match_ · _earn a salary_ · _gain experience_    |
| job / work           | countable position / uncountable activity         | _a good job_ · _hard work_                               |
| teach / learn        | give knowledge / get knowledge                    | _She teaches me._ · _I learn from her._                  |

## Similar Spelling, Different Word

| Pair                    | Difference                                    | Example                                                   |
| ----------------------- | --------------------------------------------- | --------------------------------------------------------- |
| accept / except         | receive / excluding                           | _accept the offer_ · _everyone except me_                 |
| advice / advise         | noun / verb                                   | _give advice_ · _I advise you_                            |
| loose / lose            | not tight / misplace                          | _loose shirt_ · _lose the game_                           |
| quiet / quite           | silent / fairly                               | _a quiet room_ · _quite good_                             |
| beside / besides        | next to / in addition                         | _sit beside me_ · _besides that_                          |
| desert / dessert        | dry land / sweet dish                         | _the Sahara desert_ · _ice cream for dessert_             |
| stationary / stationery | not moving / writing materials                | _a stationary car_ · _buy stationery_                     |
| principal / principle   | head of school, main / a rule                 | _the school principal_ · _a matter of principle_          |
| complement / compliment | completes / praise                            | _wine complements the meal_ · _thanks for the compliment_ |
| practice / practise     | noun / verb (BrE; AmE uses practice for both) | _piano practice_ · _practise daily_                       |

## Notes

- When two words differ only in word class (advice/advise, practice/practise), identify the gap's function first — see [Word Formation](/English/Grammar/Concepts/Word Formation).
- lie/lay is the hardest pair even for natives — keep the conjugations straight: lie-lay-lain-lying (recline), lay-laid-laid-laying (put), lie-lied-lied-lying (fib).
