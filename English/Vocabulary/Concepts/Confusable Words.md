# Confusable Words — Từ dễ nhầm lẫn

Các cặp từ trông giống, đọc giống, hoặc dịch giống nhau nhưng khác nghĩa/cách dùng — nguồn đáp án nhiễu ưa thích của đề thi.

## Cùng gốc, khác nghĩa

| Cặp                          | Khác biệt                                    | Ví dụ                                               |
| ---------------------------- | -------------------------------------------- | --------------------------------------------------- |
| economic / economical        | thuộc kinh tế / tiết kiệm                    | _economic growth_ vs _an economical car_            |
| historic / historical        | quan trọng trong lịch sử / liên quan lịch sử | _a historic victory_ vs _historical records_        |
| sensible / sensitive         | hợp lý / dễ tổn thương, nhạy cảm             | _a sensible decision_ vs _sensitive skin_           |
| continual / continuous       | lặp lại có ngắt quãng / không ngắt quãng     | _continual interruptions_ vs _continuous noise_     |
| uninterested / disinterested | chán / vô tư, công bằng                      | _uninterested in sports_ vs _a disinterested judge_ |
| electric / electrical        | chạy bằng điện / liên quan điện              | _an electric guitar_ vs _electrical engineering_    |
| childish / childlike         | trẻ con (tiêu cực) / ngây thơ (tích cực)     | _childish behaviour_ vs _childlike wonder_          |

## Khác chức năng

| Cặp                  | Khác biệt                                      | Ví dụ                                                    |
| -------------------- | ---------------------------------------------- | -------------------------------------------------------- |
| affect / effect      | động từ / danh từ                              | _The news affected me._ · _The effect was big._          |
| rise / raise         | nội động (tự tăng) / ngoại động                | _Prices rise._ · _Raise your hand._                      |
| lie / lay            | nằm (lie-lay-lain) / đặt xuống (lay-laid-laid) | _Lie down._ · _Lay the book on the table._               |
| borrow / lend        | mượn từ / cho mượn                             | _Can I borrow your pen?_ · _Lend me your pen._           |
| imply / infer        | ngụ ý (người nói) / suy ra (người nghe)        | _He implied it._ · _I inferred it._                      |
| emigrate / immigrate | rời khỏi một nước / nhập vào một nước          | _emigrate from VN_ · _immigrate to Canada_               |
| bring / take         | về phía người nói / ra xa người nói            | _Bring it here._ · _Take it there._                      |
| remember / remind    | tự nhớ / làm ai nhớ lại                        | _I remember him._ · _You remind me of him._              |
| say / tell           | say sth / tell sb (sth)                        | _She said hello._ · _She told me a story._               |
| look / see / watch   | hướng mắt / nhìn thấy / theo dõi một khoảng    | _Look at the sky._ · _I see a star._ · _Watch the film._ |
| win / earn / gain    | thắng trận/giải / kiếm tiền / tích lũy dần     | _win the match_ · _earn a salary_ · _gain experience_    |
| job / work           | vị trí đếm được / hoạt động không đếm được     | _a good job_ · _hard work_                               |
| teach / learn        | truyền kiến thức / tiếp thu kiến thức          | _She teaches me._ · _I learn from her._                  |

## Chính tả giống, từ khác

| Cặp                     | Khác biệt                                         | Ví dụ                                                     |
| ----------------------- | ------------------------------------------------- | --------------------------------------------------------- |
| accept / except         | nhận / ngoại trừ                                  | _accept the offer_ · _everyone except me_                 |
| advice / advise         | danh từ / động từ                                 | _give advice_ · _I advise you_                            |
| loose / lose            | lỏng / đánh mất                                   | _loose shirt_ · _lose the game_                           |
| quiet / quite           | yên tĩnh / khá                                    | _a quiet room_ · _quite good_                             |
| beside / besides        | bên cạnh / thêm vào đó                            | _sit beside me_ · _besides that_                          |
| desert / dessert        | sa mạc / món tráng miệng                          | _the Sahara desert_ · _ice cream for dessert_             |
| stationary / stationery | đứng yên / văn phòng phẩm                         | _a stationary car_ · _buy stationery_                     |
| principal / principle   | hiệu trưởng, chính / nguyên tắc                   | _the school principal_ · _a matter of principle_          |
| complement / compliment | bổ sung / lời khen                                | _wine complements the meal_ · _thanks for the compliment_ |
| practice / practise     | danh từ / động từ (BrE; AmE dùng practice cả hai) | _piano practice_ · _practise daily_                       |

## Ghi chú

- Khi hai từ chỉ khác từ loại (advice/advise, practice/practise), xác định chức năng của chỗ trống trước — xem [Word Formation](/English/Grammar/Concepts/Word Formation).
- lie/lay là cặp khó nhất ngay cả với người bản xứ — nhớ rõ cách chia: lie-lay-lain-lying (nằm), lay-laid-laid-laying (đặt), lie-lied-lied-lying (nói dối).
