# Learning Resources

Curated references and tools by skill — complements the phased plan in [English Roadmap](/English/Resources/English Roadmap).

## Grammar References

- **English Grammar in Use** (Raymond Murphy) — the standard self-study grammar book; Elementary (red) → Intermediate (blue) → Advanced (green).
- **Practical English Usage** (Michael Swan) — reference for tricky points and learner questions.
- **Oxford Practice Grammar** — exercise-driven alternative to Murphy.
- **British Council LearnEnglish** (learnenglish.britishcouncil.org) — free graded grammar lessons.
- **Perfect English Grammar** (perfect-english-grammar.com) — clear explanations + printable exercises.

## Dictionaries

- **Cambridge Dictionary** — IPA (BrE + AmE), learner definitions, examples.
- **Oxford Learner's / Longman** — collocations and usage notes included.
- **OZDIC / SkELL** — collocation lookup and example sentences.
- **YouGlish** — hear a word pronounced inside real videos.

## Listening

- **VOA Learning English / BBC Learning English** — graded-speed news and lessons.
- **ESLPod / Luke's English Podcast** — learner-focused podcasts.
- **TED-Ed / TED Talks** — with transcripts and subtitles for intensive listening.
- **YouTube channels:** engVid (free lessons by topic), English with Lucy, Rachel's English (AmE pronunciation).

## Reading

- **Graded readers** (Oxford Bookworms, Penguin Readers) — level-matched books for extensive reading.
- **Breaking News English** — news articles in graded levels with exercises.
- **News in Levels** — same story at three difficulty levels.

## Vocabulary

- **English Vocabulary in Use** (Cambridge) — topic-based vocabulary series.
- **English Collocations in Use** (Cambridge) — the collocation companion.
- **Anki / Memrise / Quizlet** — spaced-repetition flashcards.
- **4000 Essential English Words** — frequency-graded wordlists with exercises.

## Speaking

- **italki / Preply** — affordable online tutors for real conversation.
- **ELSA Speak** — pronunciation feedback per phoneme.
- **HelloTalk / Tandem** — language-exchange with native speakers.

## Exam Prep

- **Cambridge IELTS series** — official practice tests.
- **IELTS Liz / IELTS Simon** — free strategy lessons and model answers.
- **ETS TOEIC official materials** — authentic test items.

## Notes

- One resource per skill at a time — finishing one book beats sampling five.
- Prefer resources with audio + transcripts so listening and reading reinforce each other.
