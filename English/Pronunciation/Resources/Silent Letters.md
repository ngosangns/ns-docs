# Silent Letters

English spelling keeps letters that are never pronounced — the rules below cover the recurring patterns.

## By Letter

| Silent letter | Pattern                                    | Examples                                                                                        |
| ------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **b**         | mb at word end; bt                         | climb, comb, lamb, thumb, bomb, debt, doubt, subtle                                             |
| **c**         | sc before e/i (sometimes)                  | science, scene, scissors, muscle                                                                |
| **d**         | dge; some clusters                         | bridge, edge, Wednesday, handsome, sandwich                                                     |
| **e**         | word-final e (magic e lengthens the vowel) | name, time, hope, cute, write                                                                   |
| **g**         | gn; gh before t                            | sign, design, foreign, campaign, gnaw, high, light, night, thought, through, daughter, neighbor |
| **h**         | word-initial h; gh at start; rh            | hour, honest, honour, heir, ghost, rhyme, rhythm                                                |
| **k**         | kn at word start                           | know, knee, knife, knock, knowledge, knit                                                       |
| **l**         | lk, lf, lv before consonants               | walk, talk, could, should, would, half, calf, calm, palm, salmon                                |
| **n**         | mn at word end                             | autumn, column, damn, hymn, solemn                                                              |
| **p**         | pn, ps, pt at word start                   | pneumonia, psychology, receipt, cupboard                                                        |
| **s**         | occasional                                 | island, aisle, debris                                                                           |
| **t**         | -sten, -stle, -ften                        | listen, fasten, castle, whistle, often (AmE can sound it), soften                               |
| **u**         | after g before a vowel                     | guess, guide, guilt, guitar, building, dialogue                                                 |
| **w**         | wr at word start; before h; -sw-           | write, wrong, wrap, who, whole, sword, answer, two                                              |

## Watch Out — Similar Words Where the Letter ISN'T Silent

- climb (silent b) vs climbing — still silent; but **bombard** sounds the b.
- sign (silent g) vs **signature, signal, design** → designation — the g wakes up in related forms.
- **often** — both /ˈɒfən/ and /ˈɒftən/ exist; the t-less form is safer.
- **historic / hotel / human** — h is pronounced (it's only silent in hour, honest, honour, heir and a few loans).

## Notes

- Silent letters are fossil history — they usually mark an older pronunciation, not a rule you can predict perfectly; memorize the high-frequency words above.
- For the endings that MUST be pronounced (they carry grammar), see [Ending Sounds](/English/Pronunciation/Concepts/Ending Sounds) — the opposite problem: letters learners skip that should sound.
