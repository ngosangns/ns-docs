# Conjunctions And Connectives

Conjunctions and connectives join words, clauses, and sentences — showing addition, contrast, cause, result, or sequence.

## Coordinating Conjunctions — FANBOYS

Join two **equal** elements (words, phrases, or independent clauses): **for, and, nor, but, or, yet, so**.

| Conjunction | Meaning                    | Example                                                       |
| ----------- | -------------------------- | ------------------------------------------------------------- |
| and         | addition                   | _She sings and dances._ (Cô ấy hát và nhảy.)                  |
| but / yet   | contrast                   | _He is poor but honest._ · _She tried hard, yet she failed._  |
| or / nor    | choice / negative addition | _Tea or coffee?_ · _He doesn't smoke, nor does he drink._     |
| for         | reason (formal)            | _He stayed home, for he was ill._                             |
| so          | result                     | _It rained, so we stayed in._ (Trời mưa nên chúng tôi ở nhà.) |

## Correlative Conjunctions — Pairs

- **both ... and:** _Both John and Mary came._
- **either ... or:** _Either you apologize or you leave._ (Hoặc bạn xin lỗi, hoặc bạn rời đi.)
- **neither ... nor:** _Neither the teacher nor the students knew._ — verb agrees with the nearer subject.
- **not only ... but also:** _She is not only smart but also kind._ — with inversion when fronted: _Not only did he win, but he also broke the record_ — see [Inversion](/English/Grammar/Concepts/Inversion).
- **whether ... or:** _Whether you like it or not, we have to go._

## Subordinating Conjunctions

Introduce a dependent clause and join it to a main clause — the full inventory by meaning is in [Adverbial Clauses](/English/Grammar/Concepts/Adverbial Clauses).

- Time: when, while, before, after, since, until, as soon as.
- Reason: because, since, as, now that.
- Concession: although, though, even though, while.
- Condition: if, unless, provided that, as long as — see [Conditional Sentences](/English/Grammar/Concepts/Conditional Sentences).
- Purpose/result: so that, in order that, so ... that, such ... that.
- Comparison: as ... as, than.

## Sentence Connectors (Conjunctive Adverbs)

Link **independent** sentences or clauses — they need a semicolon or full stop, not a comma alone.

| Function | Connectives                                                    | Example                                              |
| -------- | -------------------------------------------------------------- | ---------------------------------------------------- |
| Addition | moreover, furthermore, besides, in addition, also              | _The plan is cheap; moreover, it is effective._      |
| Contrast | however, nevertheless, nonetheless, on the other hand, whereas | _He is rich; however, he is not happy._              |
| Result   | therefore, thus, consequently, as a result, hence              | _It rained; therefore, the match was cancelled._     |
| Sequence | first, then, next, finally, afterwards, meanwhile              | _First boil the water; then add the rice._           |
| Example  | for example, for instance, such as                             | _Some sports, for example football, are team games._ |
| Emphasis | in fact, indeed, above all                                     | _The job is hard; in fact, it is exhausting._        |

## Conjunction vs Preposition — Clause vs Phrase

The classic exam contrast:

| Clause (S + V)        | Phrase (noun / V-ing)        |
| --------------------- | ---------------------------- |
| because, since, as    | because of, due to, owing to |
| although, even though | despite, in spite of         |
| if, unless            | without, but for             |
| when, while           | during                       |
| so that               | to, in order to, so as to    |

- _Although it rained, we went out._ = _Despite the rain, we went out._
- Conversion patterns: Models 1–2 of [Sentence Transformation Patterns](/English/Grammar/Concepts/Sentence Transformation Patterns).

## Notes

- Do not stack two connectors with the same function: "Although it rained, but we went out" is wrong — pick one.
- Comma rules: a comma before a coordinating conjunction joining two independent clauses (_He was tired, so he slept._); a comma after a fronted subordinate clause (_Because it rained, we stayed in._).
