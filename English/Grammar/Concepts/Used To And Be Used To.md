# Used To And Be Used To

Three similar-looking structures with different meanings: **used to + V**, **be used to + V-ing**, and **get used to + V-ing**.

## Used To + Base Verb — Past Habit or State

Describes an action or state that happened regularly in the past **but no longer happens**.

**Formula:** S + used to + V (bare)

- _I used to play football every weekend._ (Tôi từng chơi bóng đá mỗi cuối tuần — bây giờ không nữa.)
- _She used to live in the countryside._ (Cô ấy từng sống ở nông thôn.)
- Negative: _I didn't use to like coffee._ / _I used not to like coffee._
- Question: _Did you use to smoke?_

## Would + Base Verb — Repeated Past Actions

"Would" also describes repeated past actions — but **only actions, never states**.

- _When we were kids, we would swim in the river every summer._ (Hồi nhỏ, chúng tôi thường bơi sông mỗi mùa hè.)
- _He would always bring me flowers._ (Anh ấy thường mang hoa cho tôi.)
- Wrong: "I would be shy as a child." (a state → use "used to be")

## Be Used To + Noun/V-ing — Familiarity

Describes something that is **normal or familiar** now — "to" here is a preposition, so it takes a noun or gerund.

**Formula:** S + be + used to + noun / V-ing

- _I am used to the noise._ (Tôi đã quen với tiếng ồn.)
- _She is used to working night shifts._ (Cô ấy đã quen làm ca đêm.)
- Works in any tense: _He was used to driving on the left._

## Get Used To + Noun/V-ing — Becoming Familiar

Describes the **process** of becoming familiar.

**Formula:** S + get + used to + noun / V-ing

- _You will get used to the weather._ (Bạn sẽ dần quen với thời tiết.)
- _I'm getting used to waking up early._ (Tôi đang dần quen dậy sớm.)

## Comparison

| Structure           | Followed by     | Meaning                             | Example                                       |
| ------------------- | --------------- | ----------------------------------- | --------------------------------------------- |
| used to + V         | bare infinitive | past habit/state, now finished      | _I used to smoke._ (Tôi từng hút thuốc.)      |
| be used to + V-ing  | gerund/noun     | accustomed — it feels normal        | _I am used to smoking._ (Tôi quen hút thuốc.) |
| get used to + V-ing | gerund/noun     | in the process of becoming familiar | _I am getting used to smoking less._          |

## Notes

- The trap is the "-ing" after "to": in "used to + V" the "to" is an infinitive marker; in "be/get used to" it is a preposition → gerund.
- Related: **be accustomed to + V-ing** is a formal synonym of "be used to" — see Model 31 of [Sentence Transformation Patterns](/English/Grammar/Concepts/Sentence Transformation Patterns).
