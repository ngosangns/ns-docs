# Conditional Sentences

A conditional sentence links **a condition** (the if-clause) to **a result** (the main clause).

## The Four Types

| Type   | Meaning                 | If-clause          | Main clause            | Example                                                                         |
| ------ | ----------------------- | ------------------ | ---------------------- | ------------------------------------------------------------------------------- |
| Type 0 | General truths, facts   | If + S + V (pres.) | S + V (present simple) | _If you heat ice, it melts._ (Nếu bạn đun nóng đá, nó tan.)                     |
| Type 1 | Real, possible future   | If + S + V (pres.) | S + will/can/may + V   | _If you study hard, you will pass._ (Nếu bạn học chăm, bạn sẽ đậu.)             |
| Type 2 | Unreal present/future   | If + S + V2/ed     | S + would/could + V    | _If I were you, I would take the job._ (Nếu tôi là bạn, tôi sẽ nhận công việc.) |
| Type 3 | Unreal, impossible past | If + S + had + V3  | S + would have + V3    | _If she had left earlier, she would have caught the train._                     |

**Notes on the types:**

- Type 1 can use **imperatives** in the main clause: _If you see him, tell him to call me._
- In type 2, use **were** for all persons in formal English: _If I were rich..._
- When the clauses refer to different time frames, types mix — see [Mixed Conditionals](/English/Grammar/Concepts/Mixed Conditionals).

## Alternatives to "If"

- **Unless** = if ... not: _Unless it rains, we will go out._ (= If it doesn't rain...)
- **Provided / providing (that), as long as, on condition that:** only if — emphasise a requirement.
  - _You can borrow the car as long as you drive carefully._ (Bạn có thể mượn xe miễn là bạn lái cẩn thận.)
- **In case:** a precaution — do B because A might happen. Different from "if".
  - _Take an umbrella in case it rains._ (Mang ô phòng khi trời mưa.)
- **Otherwise / or (else):** warns of the result if the condition is not met.
  - _Hurry up, or you'll miss the bus._ (Nhanh lên, không thì bạn sẽ lỡ xe buýt.)
- **But for / without + noun:** expresses a type-3 or type-2 condition without "if".
  - _But for your help, I would have failed._ (Nếu không có sự giúp của bạn, tôi đã thất bại.)
- **Supposing / imagine / what if:** introduce a hypothetical situation.
  - _Supposing you won the lottery, what would you do?_

## Conditional without "If" — Inversion

Dropping "if" and inverting the auxiliary makes a formal conditional — full treatment in [Inversion](/English/Grammar/Concepts/Inversion).

- Type 1: _Should you need help, call me._ (= If you should need...)
- Type 2: _Were I rich, I would travel the world._
- Type 3: _Had I known, I would have told you._

## Wishes

"Wish" and "if only" express unreal conditions about the present, past, or future — see [Subjunctive Mood](/English/Grammar/Concepts/Subjunctive Mood) and Model 10 of [Sentence Transformation Patterns](/English/Grammar/Concepts/Sentence Transformation Patterns).

## Notes

- Never put "will/would" in the if-clause itself: _If it rains..._ not "If it will rain...".
- A comma separates the clauses only when the if-clause comes first: _If you call, I'll answer._ but _I'll answer if you call._
