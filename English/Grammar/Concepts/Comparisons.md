# Comparisons — So sánh

So sánh cho thấy hai hay nhiều thứ khác nhau — hoặc ngang nhau — về một tính chất.

## So sánh hơn — So hai vật

**Công thức:** S + V + tính từ/trạng từ so sánh hơn + than + ...

| Loại tính từ/trạng từ         | Quy tắc                | Ví dụ                            |
| ----------------------------- | ---------------------- | -------------------------------- |
| Ngắn (1 âm tiết)              | -er                    | tall → taller, fast → faster     |
| Ngắn, tận cùng -e             | -r                     | nice → nicer, large → larger     |
| Ngắn, phụ âm-nguyên âm-phụ âm | gấp đôi chữ cuối + -er | big → bigger, hot → hotter       |
| Tận cùng phụ âm + y           | y → i + -er            | happy → happier, early → earlier |
| Dài (2+ âm tiết)              | more + tính từ         | beautiful → more beautiful       |

- _My house is bigger than yours._ (Nhà tôi lớn hơn nhà bạn.)
- _This book is more interesting than that one._

## So sánh nhất — So ba vật trở lên

**Công thức:** S + V + the + so sánh nhất + (in/of ...)

| Loại tính từ | Quy tắc                 | Ví dụ                |
| ------------ | ----------------------- | -------------------- |
| Ngắn         | -est                    | tall → the tallest   |
| Tận cùng -e  | -st                     | nice → the nicest    |
| CVC          | gấp đôi chữ cuối + -est | big → the biggest    |
| Tận cùng -y  | y → i + -est            | happy → the happiest |
| Dài          | the most + tính từ      | the most expensive   |

- _She is the tallest girl in the class._ (Cô ấy là cô gái cao nhất lớp.)
- _This is the most difficult exam I have ever taken._

## Dạng bất quy tắc

| Tính từ/trạng từ | So sánh hơn     | So sánh nhất          |
| ---------------- | --------------- | --------------------- |
| good / well      | better          | the best              |
| bad / badly      | worse           | the worst             |
| many / much      | more            | the most              |
| little           | less            | the least             |
| far              | farther/further | the farthest/furthest |
| old              | older/elder     | the oldest/eldest     |

- "Elder/eldest" chỉ dùng cho người trong gia đình và không bao giờ đi với "than": _my elder sister._

## So sánh bằng — As ... As

- **as + tính từ/trạng từ + as:** _He is as tall as his father._ (Anh ấy cao bằng bố.)
- Phủ định: **not as/so ... as:** _This film isn't as good as the book._
- Với danh từ: **as much/many ... as:** _I don't earn as much money as him._

## So sánh tiến triển và so sánh kép

- **so sánh hơn + and + so sánh hơn:** sự thay đổi liên tục.
  - _It is getting colder and colder._ (Trời ngày càng lạnh.)
  - _Life is becoming more and more expensive._
- **the + so sánh hơn ..., the + so sánh hơn ...:** hai thứ thay đổi cùng nhau.
  - _The harder you study, the better you get._ (Càng học chăm, càng giỏi.)
  - _The sooner, the better._ (Càng sớm càng tốt.)

## Từ bổ nghĩa cho so sánh

- much/far/a lot/even + so sánh hơn: _much better, far more interesting, even faster._
- a bit/a little/slightly + so sánh hơn: _a bit cheaper._
- by far + so sánh nhất: _by far the best._

## Ghi chú

- Không bao giờ đánh dấu kép: "more taller" và "the most biggest" đều sai.
- Sau "than", giữ hai vế so sánh song song: _My car is faster than yours_ (không phải "than you").
