# Comparisons

Comparisons show how two or more things differ — or are equal — in a quality.

## Comparative — Comparing Two Things

**Formula:** S + V + comparative adjective/adverb + than + ...

| Adjective/adverb type            | Rule                     | Example                          |
| -------------------------------- | ------------------------ | -------------------------------- |
| Short (1 syllable)               | -er                      | tall → taller, fast → faster     |
| Short, ending -e                 | -r                       | nice → nicer, large → larger     |
| Short, consonant-vowel-consonant | double last letter + -er | big → bigger, hot → hotter       |
| Ending consonant + y             | y → i + -er              | happy → happier, early → earlier |
| Long (2+ syllables)              | more + adjective         | beautiful → more beautiful       |

- _My house is bigger than yours._ (Nhà tôi lớn hơn nhà bạn.)
- _This book is more interesting than that one._

## Superlative — Comparing Three or More

**Formula:** S + V + the + superlative + (in/of ...)

| Adjective type | Rule                 | Example              |
| -------------- | -------------------- | -------------------- |
| Short          | -est                 | tall → the tallest   |
| Ending -e      | -st                  | nice → the nicest    |
| CVC            | double letter + -est | big → the biggest    |
| Ending -y      | y → i + -est         | happy → the happiest |
| Long           | the most + adjective | the most expensive   |

- _She is the tallest girl in the class._ (Cô ấy là cô gái cao nhất lớp.)
- _This is the most difficult exam I have ever taken._

## Irregular Forms

| Adjective/adverb | Comparative     | Superlative           |
| ---------------- | --------------- | --------------------- |
| good / well      | better          | the best              |
| bad / badly      | worse           | the worst             |
| many / much      | more            | the most              |
| little           | less            | the least             |
| far              | farther/further | the farthest/furthest |
| old              | older/elder     | the oldest/eldest     |

- "Elder/eldest" is only for family members and never with "than": _my elder sister._

## Equal Comparison — As ... As

- **as + adjective/adverb + as:** _He is as tall as his father._ (Anh ấy cao bằng bố.)
- Negative: **not as/so ... as:** _This film isn't as good as the book._
- With nouns: **as much/many ... as:** _I don't earn as much money as him._

## Progressive and Double Comparatives

- **comparative + and + comparative:** a continuing change.
  - _It is getting colder and colder._ (Trời ngày càng lạnh.)
  - _Life is becoming more and more expensive._
- **the + comparative ..., the + comparative ...:** two things change together.
  - _The harder you study, the better you get._ (Càng học chăm, càng giỏi.)
  - _The sooner, the better._ (Càng sớm càng tốt.)

## Modifiers of Comparison

- Much/far/a lot/even + comparative: _much better, far more interesting, even faster._
- A bit/a little/slightly + comparative: _a bit cheaper._
- By far + superlative: _by far the best._

## Notes

- Never double-mark: "more taller" and "the most biggest" are wrong.
- After "than" in comparisons, keep the compared items parallel: _My car is faster than yours_ (not "than you").
